# 보안팀 근무표·업무문서 앱

Streamlit 기반 야간·평일 주간·주말/공휴일 주간 근무표 및 업무문서 앱입니다.

## AI가 작업을 이어받을 때

Claude·GPT/Codex·Gemini 모두 같은 순서로 확인합니다. 도구마다 지침 자동 로딩 여부가 다르므로 파일을 실제로 읽었는지 확인하세요.

1. [AGENTS.md](AGENTS.md): 현재 확정 규칙, 파일 담당·병행 작업, 저장·최신화 절차.
2. [다음세션_인수인계.md](다음세션_인수인계.md): 현재 상태, 미완료 작업, 검증 범위.
3. `git status --short`와 `git log -5 --oneline`: 현재 폴더의 미커밋 변경과 최신 커밋. 다른 AI의 수정은 덮어쓰지 않습니다. 작업 중인 담당·파일은 사용자 또는 해당 작업 기록으로 확인합니다.
4. 해당 영역의 룰북·계산기준을 읽고 관련 코드와 대조합니다. 이 문서만으로 모든 동작의 검증이 끝난 것은 아닙니다.

## 실행

```powershell
.venv\Scripts\python -m streamlit run app.py --server.port 8509
```

실행 환경과 폰 접속은 [배포 안내](배포_안내.md), 관련 검사 실행 원칙은 AGENTS.md를 따릅니다.

## GitHub와 PC에서만 보관하는 자료

코드·검사·현재 문서와 추적 중인 `history/` 자료는 Git으로 보관합니다. `.venv/`, `backup/`, `logs/`, 휴지통, 자격 파일 등은 제외됩니다. `work/`는 임시 폴더이며 커밋하지 않습니다. Telegram 로그인 파일과 바탕화면 원본 양식처럼 PC 경로를 참조하는 자료는 GitHub만 복제해도 생기지 않습니다. 새 PC에서는 별도 준비가 필요합니다.

세 AI가 같은 폴더에서 작업하면 변경 파일을 즉시 공유하지만, 다른 PC·클라우드의 복제본은 최신 커밋을 받아야 합니다. GitHub는 실시간 파일 잠금을 제공하지 않습니다.
