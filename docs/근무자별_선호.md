# 근무자별 선호 기록

사용자가 직접 확인한 개인 선호를 기록한다. 필수 배정 규칙과 구분하며, 엔진 적용 여부를 따로 표시한다.

## 준호

- 확인일: 2026-10-19, 구체화 2026-10-21
- 야간 휴게 선호: **01시부터 시작하는 대폭 휴게(3시간 이상 연속 실휴게)를 선호한다.** 기존 '가급적 늦은 시간대' 선호를 사용자가 구체화한 기준이다.
- 적용 원칙: 필수규칙과 당일 피로도 균형을 우선 유지하고, 그 범위에서 고려하는 개인 선호다. 늦은 휴게를 위해 휴게 총량을 늘리거나 07시 휴게 순번을 임의로 바꾸는 뜻은 아니다.
- 상태: 사용자 선호 기록 완료. 이번 요청에서는 Solver 가중치나 배정 로직을 변경하지 않았다.
