[용어: 공휴일은 토·일·법정공휴일·대체공휴일을 모두 포함한다. 토·일 제외 조건은 법정공휴일·대체공휴일만으로 명시한다.]

0-2. 근무표 생성 전 반드시 모드 확인 근무표를 작성하기 전에 반드시 사용자에게
다음 중 어느 방식인지 확인한다.
  - 유도리 근무표
  - FM 근무표

사용자의 명시적 선택 없이 두 모드의 전용 규칙을 임의로 혼합하지 않는다.

0-2-1. FM 선택 시 FM·유도리 동시 만족 우선 [2026-10-02 사용자 확정]
  - 사용자가 FM을 고르면 같은 표를 FM과 유도리(10-1 I1 22~03시 휴게성, 10-4 20시 설치, 10-5
    04시 I1 철수)로 각각 계산해 다음 순서로 찾는다. 두 모드의 규칙을 섞는 것이 아니라 두 모드를
    각각 따로 만족시키는 것이다.
      1) 두 기준 모두 하드룰 + 두 기준 모두 17장 당일 목표(전일 일반근무자 피로도 최대-최소 1점
         이하, 실휴게 1시간 이하) [2026-10-02 사용자 확정: 하드룰만 보면 10/15 표처럼 유도리 기준
         피로도 차이 2가 나올 수 있었음]
      2) 1)이 불가능하면 두 기준 모두 하드룰만
      3) 그것도 불가능하면 FM 하드룰만
  - 근무표 자체(표시 배정·저장 이력)는 FM으로 계산·저장한다. 그 밖의 밸런스 목표는 FM 기준이다.
  - 결과에 'FM·유도리 모두 만족' / 'FM·유도리 하드룰만 만족(두 기준 차이 표시)' / 'FM만 만족'을 표시한다.
  - 2026-10-02 조사: FM만 보고 만든 표는 유도리로 계산하면 I1 00~03시 담당자의 피로도가 줄어
    통제A와의 격차 규칙(8-4-2·H-15)에 자주 걸렸으나, 처음부터 두 기준을 함께 찾으면 결원 1명
    N1~N4 모두 격차 규칙을 완화하지 않고 해가 있었다.
  - 유도리 선택, 0-4·0-4-1 자동 유도리 전환, 관리자 교대 근무표, 21-8 진단에는 적용하지 않는다.

0-3. 모드 정의 유도리 모드
  - 상위관리자 없이 조원과 당일 관리자 중심으로 실제 운영상 유연성을 적용하는
    방식.
  - 심야 I1 휴게성 전환, 실제 좌식 전환 등 내부 운영 유연성을 허용한다.

FM 모드
  - 상위관리자 존재, 점검, 감사, 기타 이유로 회사의 원칙적 근무형태를 그대로
    지켜야 하는 방식.
  - 이 문서에서 별도로 정한 FM 전용 차이점을 제외하면 공통 코어 규칙은
    유도리와 동일하다.

0-4. FM 결원 2명 자동 전환
  - 일반근무자 결원 2명(일반근무자 4명 출근) 조건에서는 FM 정상근무가 불가능한
    것으로 간주한다.
  - 이 경우 FM 해를 억지로 찾지 않고 자동으로 유도리 모드로 전환하여 작성한다.
  - 전환 사실을 결과에 명시한다.
  - 일반근무자 결원 0명 또는 1명(6명 또는 5명 출근) FM은 정상 FM 모드로
    검토한다.

0-4-1. 부분가용에 의한 최소 가용인원 4명 자동 전환 [v2.18, 사전편성]
  - 근무 시작 전에 확정된 연차·반차 기준으로, 어느 시간 슬롯이든 가용
    일반근무자(관리자대행 준호 제외)가 4명이면 회차 전체를 유도리 모드 + 결원
    2명(일반근무자 4명) 규칙으로 편성한다. FM을 선택했더라도 자동 전환하며,
    전환 사실과 해당 시간대를 결과에 명시한다.
  - 예: 연차 1명 + 반차 1명 -> 전환. 같은 쪽 반차 2명 -> 전환. 전반부 반차 1명
    + 후반부 반차 1명 -> 모든 슬롯 5명이므로 전환하지 않는다.
  - 결원 2명 규칙에 따라 N1/N2 남문은 저녁 18시만 운영하고 19·20시는 운영하지
    않는다. 20시 차단봉 설치는 20시 I1 + 보안실 대기 1명이다.
  - 순찰은 1인 1회로 한다(A는 21시 상층, 14-2-1). 반차자는 가용 시간대의
    순찰만 맡는다. 순찰 후 휴게는 H-11 완화형을 적용한다.
  - 가용 일반근무자가 3명 이하인 슬롯이 있으면 지원 범위 밖으로 보고 근무표를
    생성하지 않는다.
  - 근무 시작 후 긴급 재편성으로 가용인원이 줄어드는 경우에는 본 조항이 아니라
    0-4-2를 적용한다.

0-4-2. 긴급 재편성 유도리 전환 [v2.20]
  - 근무 시작 후 긴급 반차·조퇴·이탈로 LOCK 이후 남은 시간대의 가용
    일반근무자(관리자대행 제외)가 4명이 되면, LOCK 이후 첫 슬롯부터 유도리
    모드 + 결원 2명 규칙으로 전환한다. LOCK된 슬롯은 원래 모드와 실제 수행내용
    그대로 둔다(0-2의 모드 혼합 금지에 대한 명시적 예외).
  - 전환 이후 22~03시 I1은 휴게성, 04시 철수는 04시 I1 담당(10-5)이다. 20시
    설치가 전환 이후라면 20시 I1 + 보안실 대기 1명이 설치한다.
  - 전환 이후 남문은 결원 2명 기준을 따른다.
  - 남은 순찰은 14-3-1, 순찰 후 회복은 H-11 완화형 + H-11-2를 적용한다.
  - 관리자는 8-7(결원 2명일 관리자 정책)을 적용한다. 실근무 2시간·피로도 격차
    상한은 적용하지 않는다. 05시 휴게, 06시 G2, 8-3-1은 유지한다.
  - 가용 일반근무자가 3명 이하가 되면 전환하지 않고 21-8 진단을 따른다.
  - 원래 계획이 이미 결원 2명 또는 0-4-1 부분가용 결원이면 전환하지 않는다.

0-4-3. 통제A 긴급 이탈 시 준호 관리자 대행 승계 [v2.21, 2026-09-30 사용자 승인]
  - 근무 중 통제A가 긴급 반차·이탈하면 A가 빠지는 시간부터 준호가 관리자
    대행을 이어받는다. 이미 지나간(LOCK) 시간대는 바꾸지 않는다.
  - 승계 이후 관리자 규칙(05시 휴게, 06시 G2, 07시 규칙, 8-7 등)은 준호가
    지고, 일반근무자는 1명 줄어든 것으로 본다(0-4-2 전환 여부도 이 기준).
  - 준호 개인의 연속근무·입식·순찰 후 휴게 제한은 승계 전후를 이어서 본다.
  - 준호가 결근이거나 반차로 끝까지 대행할 수 없으면 자동 승계하지 않는다.

0-4-4. 관리자 미리 정한 전반부·후반부 반차 (2026-10-18 사용자 요청)
  - 전반부 반차: 통제A는 18~00시 근무불가, 01시 출근. 준호가 18~00시 관리자 대행 후 01시부터 일반근무로 돌아간다.
  - 후반부 반차: 통제A는 00시까지 근무, 01시부터 근무불가. 준호가 01시부터 관리자 대행을 이어받는다.
  - 준호는 하루 전체 출근해야 자동 인계한다. 인계 전후 준호 개인의 연속근무·입식·순찰 회복 제한은 이어서 확인한다.
  - 통제A 본인 I1 최소1회(8-14)·대기 최대2회(8-15)는 실제 통제A의 출근 시간에만 센다. 준호의 대행 시간은 제외한다.
  - 기존 관리자 자리의 시간별 운영 규칙은 해당 시간의 관리자가 이어받는다. 근무불가 시간은 근무·휴게 모두 0으로 표시한다.
  - 저장 시 인계 시각과 방향을 보존한다. 과거 저장본에서 방향값이 없으면 종전 통제A→준호 인계로 읽는다.

0-5. 규칙 우선순위
1순위: 모드 선택/자동전환 규칙
2순위: 공통 하드룰
3순위: 선택된 모드의 전용 하드룰
4순위: 사용자가 당일 명시한 특수지시
5순위: 가능한 범위에서 당일 관리자의 실근무시간 최소 우선. 단, A 결근으로
준호가 관리자대행인 경우에만 같은 실근무시간이면 준호의 피로도 최소를 추가
적용한다. 결원 2명 회차(정식 결원 2명, 0-4-1, 0-4-2 전환 이후)에는 5순위
관리자 우대를 적용하지 않고 8-7을 따른다.
6순위: 일반근무자 실제 밸런스, 표시상 밸런스 및 이력 최적화
  - 6순위 내부에서는 이력으로 추적 가능한 소프트룰의 미충족 누적(soft debt)을
    반영한다. 같은 소프트룰이라면 이전 회차에서 미충족이 누적된 대상일수록
    다음 적용 가능한 회차에서 더 강하게 충족을 우선한다. 단, 어떤 경우에도
    하드룰이나 1~5순위보다 우선하지 않는다.

관리자 최소부담 원칙
  - 모드와 관계없이, 일반근무자 결원 0명·1명 회차에 적용하는 우선 선호다. 결원
    2명 회차(정식 결원 2명, 0-4-1 부분가용 자동전환, 0-4-2 긴급 전환 이후)에는
    제8장 8-7의 결원 2명 관리자 정책이 우선하며, 관리자 최소부담 우대와
    관리자-일반근무자 격차 상한만 해제한다. 관리자 고정규칙(05시 휴게, N1/N3
    06시 G2, 8-3/8-3-1 등)은 결원 2명 회차에도 그대로 적용한다.
  - 필수 포스트, 관리자 고정업무 및 모든 하드룰을 먼저 충족한 범위에서
    적용한다.
  - 관리자의 근무를 0시간으로 고정하거나 고정업무를 면제하는 하드룰이 아니다.
  - A 출근 시 통제 A는 실제 근무시간 최소화만 관리자 우대 최적화 목표로
    사용한다. A의 실제 근무시간이 동일한 복수의 정상해 사이에서는 A 개인의
    피로도가 더 낮다는 이유만으로 해당 해를 우선하지 않는다.
  - A 결근으로 준호가 관리자대행인 경우에는 기존 보호를 유지하여, 준호의 실제
    근무시간 최소 -> 같은 실제 근무시간이면 준호 개인 피로도 최소 순으로
    적용한다.
  - 두 경우 모두 관리자와 각 출근 일반근무자의 실근무시간 차이 2시간 상한 등
    별도로 정의된 HARD는 그대로 지킨다(결원 2명 회차 제외, 8-7).

당일 특수지시가 하드룰과 충돌할 경우 자동으로 하드룰을 깨지 않고 사용자에게
충돌 사실을 알린다.

제1장. 야간 유형 정의
============================================================

N1 = 평일 야간 시작 -> 다음날 평일 주간 N2 = 평일 야간 시작 -> 다음날
주말/공휴일 주간 N3 = 주말/공휴일 야간 시작 -> 다음날 평일 주간 N4 =
주말/공휴일 야간 시작 -> 다음날 주말/공휴일 주간

사용자 표시 표준
  - 사용자 화면, 결과 요약, 검증 결과, 설정 요약 등에서 N유형을 표시할 때는
    가능한 주요 위치에서 아래 의미를 함께 병기한다.
  - N1 (평일 → 평일)
  - N2 (평일 → 공휴일)
  - N3 (공휴일 → 평일)
  - N4 (공휴일 → 공휴일)
  - 위 표기는 사용자 이해를 위한 표시 표준이며 N유형 판정 로직 자체를 변경하지
    않는다.
  - 본문 과거 표현의 '주말/공휴일'은 N유형 판정 범주를 설명하는 용어이며,
    사용자 UI 표시는 위의 간결한 표준을 우선한다.

핵심 해석
  - 야간 시작일이 평일이면 18, 19, 20시에 남문 운영이 존재할 수 있다.
  - 다음날이 평일이면 06, 07시에 남문 운영이 존재한다.
  - 주말/공휴일 야간 시작 시 18~20시 남문은 기본 미운영이다.
  - 주말/공휴일 종료 시 06~07시 남문은 기본 미운영이다.
  - 행사/의전/특수상황으로 약 1시간 남문이 추가될 수 있으며 이는 당일
    입력값이다.

제2장. 근무자 구성, 결원수 및 관리자 상태
============================================================

2-1. 일반근무자 기본 편성 및 결원수 표준
  - 일반근무자 기본 편성은 6명이다.
  - 일반근무자 결원은 최대 2명까지 허용한다.
  - 본 룰북에서 인원 조건은 아래 표현을 표준으로 사용한다.
  - 결원 0명 = 일반근무자 6명 출근
  - 결원 1명 = 일반근무자 5명 출근
  - 결원 2명 = 일반근무자 4명 출근
  - 이후 '결원 0명/1명/2명'이라는 표현은 특별한 설명이 없는 한 위 일반근무자
    결원수를 뜻한다.
  - 통제 A의 결근은 일반근무자 결원수에 포함하지 않는다.
  - A 결근으로 준호가 관리자대행으로 전환되어도 그 자체로 일반근무자 결원수가
    바뀌는 것은 아니다.
  - 근무표 표시는 일반근무자 1~6번 번호를 사용한다.
  - 실제 직원 신원은 번호와 별도 저장한다.
  - 누적 이력은 번호가 아니라 실제 직원 기준으로 추적한다.

2-2. 관리자 상태 표준
  - 관리자 상태는 아래 두 가지로만 구분한다. 1) A 출근: 통제 A가 정상 관리자.
    2) A 결근(준호 대행): 준호가 통제 A의 관리자 역할을 대행.
  - 통제 A와 준호가 동시에 결근하는 경우는 현재 프로젝트 범위에서 발생하지
    않는 조건으로 본다.
  - 따라서 A 결근 시에는 별도 선택 없이 준호 관리자대행을 적용한다.
  - A의 출근/결근은 일반근무자 결원 0/1/2명과 별개의 조건축으로 관리한다.

2-3. A 출근 시 통제 A와 준호
  - 통제 A는 정상 관리자다.
  - 통제 A는 일반근무자 밸런스 집계에서 기본적으로 제외한다.
  - 통제 A는 G1/L3/I1 등 일반 포스트를 실제로 수행할 수 있다.
  - A가 출근한 날 준호는 일반근무자와 완전히 동일한 신분과 규칙을 적용한다.

2-4. A 결근 시 준호 관리자대행
  - A 결근 시 준호는 그 회차에서 통제 A와 동일한 관리자 자격, 의무, 포스트
    자격 및 A 전용 규칙을 적용받는다.
  - 관리자대행 준호는 일반근무자 밸런스 비교 대상에서 제외한다.
  - 관리자대행 준호는 A와 동일하게 G1/L3/I1 등 일반 포스트를 실제로 수행할 수
    있다.
  - 제8장의 05시 휴게, 06시 G2, 07시 운영, 관리자 최소부담, 실근무 격차,
    피로도 격차, 결원 0명 조건 심야 연속근무 제한을 모두 준호에게 동일 적용한다.
    (04시 I1 선호 8-6은 2026-10-05 삭제)

제3장. 시간 범위와 기본 포스트
============================================================

시간 슬롯
  - 18:00 시작부터 07:00 시작까지 총 14개 시간 슬롯을 사용한다.

기본 포스트
  - G1: 매 시간 실제 근무자 1명 필요.
  - L3: 매 시간 표기자 1명 필요.
  - I1: 매 시간 표기자 1명 필요.

비포스트 인원
  - 포스트/순찰에 배정되지 않은 사람은 반드시 다음 중 하나로 표기한다.
  - 보안실 대기
  - 휴게
  - 빈칸으로 두지 않는다.

보안실 대기
  - 원칙적으로 휴게성 시간이다.
  - 단, 차단봉 설치/철수 등 별도 업무를 수행하면 해당 업무 규칙을 적용한다.
  - 모드와 인원수에 관계없이 20시와 04시에는 보안실 대기자를 최소 1명
    표시한다.
  - 04시는 보안실 표시를 정확히 1명만 둔다. 포스트/순찰/차단봉 등 필수업무
    배정 후 보안실 대기 가능 인원이 2명 이상이어도 보안실에는 1명만 표시하고,
    나머지 비포스트 인원은 휴게로 표기한다.
  - 20시는 보안실 표시를 최대 2명까지만 둔다. 필수업무 배정 후 보안실 대기
    가능 인원이 2명 이상이면 정확히 2명을 보안실로 표시하고, 1명만 가능하면
    1명을 표시한다. 3명 이상을 보안실에 표시하지 않는다.
  - 그 외 시간은 보안실 대기 0명을 허용하며, 포스트/순찰/차단봉 업무가 없는
    나머지 인원은 휴게로 표기한다.
  - [2026-10-01 추가] FM 시간(20시·04시 제외)에는 포스트/순찰에 들어가지 않은
    사람이 2명 이상이면 정확히 1명을 보안실 대기, 나머지는 휴게로 표기한다.
    1명 이하면 보안실 대기 없이 휴게로 표기한다. 순찰 후 휴게로 지정된 사람은
    보안실 대기로 표기하지 않는다.
  - 이 보안실 대기는 근무표 전체에서 사람마다 횟수가 고르게 돌아가도록 배치한다.
  - 차단봉을 수행하는 보안실 담당자는 해당 시간의 필수 보안실 인원에 포함한다.
  - 보안실 담당자 선택은 다른 하드룰과 실제 밸런스를 지키는 범위에서 정한다.
  - N1/N2 18시 당일 관리자는 L3에 표시되지만 실제로 보안실 대기한다. 보안실
    열에 관리자를 중복표기하지 않는다.

1인 1시간 1개 실제 주업무 [하드]
  - 한 사람은 같은 시간 슬롯에 원칙적으로 하나의 실제 주업무만 수행한다.
  - G1/L3/I1/남문/순찰 등 서로 다른 실제 주업무의 동시 수행은 금지한다.
  - 차단봉처럼 본 문서에서 명시적으로 포스트와의 겸임을 허용한 특수업무만
    예외로 한다.
  - 표시와 실제가 다른 특수운영 시간에는 actual_post_or_work_type 기준으로
    판정한다.

제4장. 표시 배정과 실제 근무를 분리하는 데이터 모델
============================================================

모든 사람/시간대에 최소 다음 항목을 별도 관리한다.
  - displayed_assignment
  - actual_post_or_work_type
  - fatigue_value
  - actual_work_time_value
  - actual_rest_time_value
  - posture_or_mode: standing / seated / rest-like
  - counts_for_same_post_consecutive
  - counts_for_continuous_work_restriction
  - counts_as_meal_opportunity
  - counts_as_post_patrol_rest
  - barrier_install_flag
  - barrier_remove_flag
  - mode: flexible / FM

중요 원칙
  - 근무표에 무엇이 적혀 있는가와 실제로 무엇을 했는가는 별도 차원이다.
  - 밸런스 계산은 실제 수행 기준이 1순위다.
  - 표시상 배정은 별도 보조 최적화 대상으로 관리한다.

제5장. N1~N4 및 남문 운영
============================================================

5-1. 야간 시작이 평일인 N1/N2

결원 0명(일반근무자 6명 출근)
  - 18시 남문 일반근무자 2명: G2 1명 + G3 1명.
  - 19시 남문 일반근무자 1명: G2.
  - 20시 남문 일반근무자 1명: G2.

결원 1명(일반근무자 5명 출근)
  - 18시 남문 일반근무자 1명: G2
  - 19시 남문 일반근무자 1명: G2
  - 20시 남문 일반근무자 1명: G2
  - 18~20시 배정자는 서로 중복하지 않는다.

결원 2명(일반근무자 4명 출근)
  - 18시 남문 일반근무자 1명: G2
  - 19시 남문 미운영
  - 20시 남문 미운영

5-1-1. 평일 시작 저녁 남문 개인별 제한 [하드]
  - N1/N2의 18/19/20시 G2·G3를 합산하여 같은 일반근무자는 최대 1회만 들어간다.
  - 시간이나 라벨을 바꾸어 2회 배정하는 것도 금지한다. 예: 18시 G3 -> 19시 G2
    금지.
  - 당일 관리자는 해당 저녁 남문에 배정하지 않는다.
  - 06/07시 남문을 이 저녁 1회 제한에 포함하지 않는다. 아침 남문은 별도 규칙을
    적용한다.

5-2. 야간 시작이 주말/공휴일인 N3/N4
  - 18~20시 정상 남문 미운영.
  - 행사/의전이 있으면 사용자 입력에 따라 예외적으로 운영 가능.

5-3. 다음날이 평일인 N1/N3

06시
  - 결원 0명(일반근무자 6명 출근): 관리자 + 일반근무자 2명 = 총 3명 남문.
  - G2: 관리자 + 일반근무자 1명.
  - G2(1): 일반근무자 1명.
  - 결원 1명 또는 2명(일반근무자 5명 또는 4명 출근): 관리자 + 일반근무자 1명 =
    총 2명 남문
  - 당일 관리자는 06시 G2 고정.

07시
  - 일반근무자 결원 0/1/2명(출근 6/5/4명)과 무관하게 일반근무자 2명이 남문: G2
    1명 + G3 1명.

5-3-1. 다음날 평일 남문 연속 배치 금지 [HARD, 2026-10-15 사용자 확정]
  - 다음날이 평일(토·일·법정·대체공휴일 제외)이면, 결원 2명 구간을 제외하고 같은 사람의 남문 2시간 연속 배치를 금지한다.
  - G2·G3·G2(1)을 남문으로 합산한다. 다른 남문 포스트로 바뀌어도 연속이다. 관리자·일반근무자, FM·유도리 모두 적용.
  - 인접한 두 시간 중 결원 2명인 시간이 있으면 그 쌍은 예외. 반차·긴급 이탈은 각 시간의 실제 가용 인원으로 판단한다.
  - 이미 두 시간 모두 LOCK된 과거 배정은 보존하며, 한 시간만 LOCK이면 다음 남문 연속 배정을 금지한다.

5-4. 다음날이 주말/공휴일인 N2/N4
  - 06~07시 정상 남문 미운영.

5-5. G1
  - G1은 남문 포스트가 아니다.
  - 남문 인원 계산에서 제외한다.

5-7. 추가 남문 생성 전 확인 [2026-10-05 사용자 확정]
  - 남문을 원래 안 여는 시간이 있는 회차(N2·N3·N4)는 근무표 생성 전에 'G2 추가 운영 시간'을
    반드시 확인받는다. '추가 없음' 또는 시간을 고르기 전에는 생성하지 않는다(PC·폰).
  - 고를 수 있는 시간: 주말/공휴일 시작(N3/N4) 18·19·20시, 다음날 주말/공휴일(N2/N4) 06·07시.
    여러 시간 선택 가능.
  - 고른 시간에는 G2 1명이 필수 포스트다. 통제 포함 누구나 들어갈 수 있다(단 8-11 등 다른
    하드룰은 그대로). 회계는 5-6과 같다.
  - 고른 값은 근무표 조건으로 저장되며 긴급 재편성에도 그대로 이어진다.

5-6. 남문 기본 회계
  - G2/G3/G2(1)는 실제 입식근무 1시간으로 계산한다.
  - 피로도 2점, 실근무 1시간, 실휴게 0시간.
  - G2(2) 등 별도 라벨의 당일 사용 여부/구체 구조는 임의로 만들지 않고
    확인한다.

============================================================
제6장. 18~19시 L3/I1 첫 타임 운영
============================================================

6-1. 평일 야간 시작 N1/N2 특수운영

18시
  - 근무표 표기: L3 = 당일 관리자
  - 당일 관리자는 실제 L3에 투입되지 않는다.
  - 실제 상태는 업무 없는 보안실 대기로 계산한다: 피로도 0점, 실근무 0시간,
    실휴게 1시간.
  - 식사기회로 인정한다. L3 표기만 보고 실제 입식근무로 집계하지 않는다.
  - I1에 표기된 일반근무자가 실제 L3 입식근무를 수행한다.
  - 해당 일반근무자 피로도 = 입식 2점.

19시
  - L3 = 당일 관리자 실제 정위치.
  - I1 표기 일반근무자 = 실제 I1 좌식근무.

주의
  - 평일 야간 첫 타임 특수운영은 N1/N2에만 적용한다.

6-2. 주말/공휴일 야간 시작 N3/N4
  - 18시부터 L3와 I1 모두 표기자가 실제 해당 포스트에 정위치한다.
  - L3를 당일 관리자로 고정하지 않는다.
  - I1도 표기자가 실제 I1 근무를 한다.
  - 평일 야간 특수배정을 적용하지 않는다.

6-2-1. 주말/공휴일 시작 통제 A 18시 휴게 고정 [하드, 2026-10-05 사용자 확정]
  - N3/N4에서 통제 A(ID A)의 18시는 항상 휴게로 표시·계산한다. L3·I1 등 18시 포스트는
    일반근무자가 맡는다.
  - A 결근 시 관리자대행(준호)에게는 적용하지 않는다.
  - 긴급 재편성에서 18시가 이미 LOCK된 과거면 기록 그대로 둔다.
  - 이 규칙으로 6-3의 N3/N4 관리자 18~19시 L3 연속 예외는 통제 A에게는 생기지 않는다.

6-3. 관리자 연속 L3 특수예외
  - N3/N4에서 당일 관리자가 실제로 18~19시 L3 연속배정을 받는 경우 관리자 한정
    특수 예외로 허용할 수 있다.
  - 그 외에는 관리자도 일반 동일포스트 연속 제한을 따른다.

============================================================
제7장. 07시 I1 실제근무 해석
============================================================

N1/N3
  - 07시 I1 표기자는 실제로 L3 입식근무를 수행한다.
  - L3 표기자도 실제 L3에 근무한다. 즉 L3/I1 두 표기자가 실제로 함께 L3 근무를
    한다.
  - 두 사람 모두 각자 피로도 2점, 실근무 1시간, 실휴게 0시간.
  - 표시상 L3 1명/I1 1명과 실제 L3 2명을 구분한다.

N2/N4
  - 07시 I1 표기자는 실제 I1 좌식근무.
  - 피로도 1점.

============================================================
제8장. 관리자(A / 대행 준호) 후반부 규칙
============================================================

공통 정의
  - 본 장에서 '관리자'는 A 출근 시 통제 A, A 결근 시 관리자대행 준호를 뜻한다.
  - A와 준호 동시 결근은 현재 프로젝트 범위에서 발생하지 않는 조건으로 본다.

8-1. 05시
  - 관리자는 반드시 휴게성 시간이어야 한다.
  - 하드룰.

8-2. 06시
  - N1/N3에서 관리자는 G2 필수.

8-3. 07시
  - N1/N3, 즉 다음날이 평일인 회차에서 관리자는 07시 반드시 실제 휴게성
    상태여야 한다. [하드]
  - 결원 0/1/2명과 무관하게 적용한다. 단, 07시 가용 일반근무자가 4명인 경우는
    8-3-1의 예외를 따른다. 그 외에는 일반근무자 밸런스나 필수 포스트 충족을
    이유로 N1/N3의 07시 관리자를 L3/I1/G1/남문/순찰/차단봉 등 실제근무에
    투입하지 않는다.
  - A 결근 시에는 관리자대행 준호에게 동일하게 적용한다.
  - N2/N4는 본 07시 휴게 하드룰의 적용 대상이 아니다. 해당 회차의 다른 관리자
    최소부담 및 공통 규칙을 따른다.

8-3-1. 07시 일반근무자 4명 예외 [v2.18, 하드]
  - N1/N3에서 07시 가용 일반근무자가 4명이면(결원 2명 또는 부분가용 결원),
    07시 5개 포스트(G1, L3, I1, 남문 G2·G3)를 채우기 위해 관리자는 07시에 L3
    또는 I1 실제근무로 배치한다. 이때 8-3의 07시 휴게 하드룰은 적용하지
    않는다.
  - 07시 가용 일반근무자가 5명 이상이면 8-3을 그대로 적용한다.
  - 긴급 재편성에도 동일하게 적용한다.

8-7. 결원 2명일 관리자 정책 [v2.18]
  - 결원 2명(정식 결원 2명 또는 0-4-1 부분가용 자동전환, 0-4-2 긴급 전환 이후)
    회차에서 관리자(A 또는 관리자대행 준호)는 실근무시간·피로도 최소화 우대를
    받지 않는다. 해제되는 것은 관리자 최소부담 우대(0-5 5순위, 8-4)와 격차
    상한(8-4-1, 8-4-2)뿐이며, 관리자 고정규칙(05시 휴게, 06시 G2, 8-3/8-3-1,
    21시 상층부 순찰 등)은 그대로 적용한다.
  - 8-4-1의 관리자-일반근무자 실근무 2시간 격차 상한과 8-4-2의 피로도 격차
    상한은 적용하지 않는다.
  - 05시 휴게성(8-1)은 하드로 유지한다.
  - N1/N3 06시 G2 고정(8-2)을 유지한다.
  - 관리자의 차단봉 설치 또는 철수 참여는 가급적 피하도록 강하게 권장한다
    [소프트, 최우선 관리자 목표].

8-4. 관리자 추가근무
  - G1/L3/I1 단독 투입 가능.
  - 아래 관리자 실근무시간 최소화 우대는 결원 0명·1명 회차에 적용한다. 결원
    2명 회차는 8-7을 따른다.
  - 관리자 추가 포스트 시간 상한은 따로 두지 않는다.
  - 단, 모든 연속근무/순찰후휴게/05시 휴게 하드룰을 지켜야 한다.
  - 가능한 범위에서 관리자 실근무시간을 먼저 최소화한다. A가 정상 관리자일
    때는 같은 실근무시간인 해들 사이에서 A 개인 피로도 최소화를 별도 관리자
    우대 목표로 사용하지 않는다. A 결근으로 준호가 관리자대행인 경우에만 같은
    실근무시간인 해들 중 준호 개인 피로도를 최소화한다.
  - 일반근무자 밸런스 개선만을 위해 관리자 추가근무를 자동으로 늘리는 방식을
    기본값으로 삼지 않는다.
  - 관리자의 필수 고정업무와 하드룰을 만족하기 위해 필요한 근무는 수행한다.
  - 관리자 최소부담과 일반근무자 밸런스의 결과를 함께 보고하되, 관리자
    최소부담 우선 원칙을 표시상 균형 때문에 뒤집지 않는다.

8-4-1. 관리자와 일반근무자의 실제근무 격차 상한
  - 관리자와 출근한 각 일반근무자의 회차 전체 실근무시간 차이는 최대 2시간
    이내로 제한한다.
  - 결원 2명 회차(정식 결원 2명, 0-4-1, 0-4-2 전환 이후)에는 적용하지
    않는다(8-7).
  - 평균과의 차이가 아니라 각 개인과의 차이를 확인한다.
  - 실근무는 포스트와 순찰만 포함한다. 차단봉만 수행한 칸은 실근무 0시간이다
    (2026-10-04 사용자 확정, 11-0 참조).
  - 이 상한 및 다른 하드룰 안에서 관리자 실근무시간을 우선 최소화한다. A 정상
    관리자일 때는 동률 해 사이에서 A 개인 피로도 최소화를 별도 우대 목표로
    사용하지 않으며, 준호 관리자대행일 때만 동률이면 준호 개인 피로도를
    최소화한다.
  - 일반근무자끼리의 피로도·휴게 밸런스 목표는 유지한다. 관리자를 과도하게
    쉬게 하기 위해 그 목표를 임의로 버리지 않는다.
  - 단, 반차·조퇴·지각 등으로 회차 전체 가용시간이 정상근무자보다 짧은
    일반근무자에게는 절대 실근무시간 차이만으로 2시간 상한을 적용하지 않는다.
    이 경우 제21장 21-7의 가용시간 대비 근무부담률 기준으로 밸런스를 비교한다.
    이는 부분가용 근무자에게 다른 연속근무·자세·순찰후휴게 등 하드룰을
    완화한다는 의미가 아니다.

8-4-2. 관리자와 일반근무자의 피로도 격차 상한
  - 결원 0명 또는 1명(일반근무자 6명 또는 5명 출근)에는 관리자와 각 출근
    일반근무자의 총피로도 차이를 최대 4점 이내로 제한한다.
  - [v2.19, 하드] 통제 A 출근 + 결원 0명 또는 1명이면, A의 총피로도는 각 출근
    일반근무자(전체가용) 이하이고 그 차이는 3점 이내로 한다(2026-10-13 사용자 승인 예외). 즉 일반근무자
    피로도
  - A 피로도 차이는 하드 0~3점이며, 정상 0~2점 유지 목표는 다른 모든 소프트룰 다음 최후순위이다.
  - 3점 예외는 다른 권장 목표를 먼저 충족시키기 위해 허용하며 무조건3점으로 벌리지 않는다.
  - FM·유도리 두 기준에 동일 적용. 준호 관리자대행일 때는 기존 4점 이내 규칙을 따른다.
  - 결원 2명(일반근무자 4명 출근)에는 이 상한을 적용하지 않는다. 결원 2명
    유도리의 관리자 최소부담 및 필수 포스트 충족 규칙을 우선한다.
  - 피로도 격차 상한은 실근무시간 차이 최대 2시간 상한과 함께 적용한다.
  - 두 상한과 다른 하드룰을 만족하는 범위에서 관리자 실근무시간 최소화를
    우선한다.

8-5. 결원 0명 조건 관리자의 00~05시 연속근무 제한
  - 결원 0명(일반근무자 6명 출근)에서는 관리자가 00~05시 구간에서 실제근무가
    2시간을 넘게 연속되지 않도록 한다.
  - 입식/좌식을 바꿨다는 이유로 연속 실제근무가 끊긴 것으로 보지 않는다.
  - 00/01/02, 01/02/03, 02/03/04, 03/04/05의 각 3개 슬롯을 모두 실제 업무로
    채우지 않는다.
  - 기존 05시 관리자 휴게 하드룰은 그대로 유지한다.
  - 결원 1명/2명(일반근무자 5명/4명 출근)에 같은 추가 제한을 임의로 확장하지
    않는다.

8-6. (삭제, 2026-10-05 사용자 확정) 관리자의 04시 I1 저우선 권장
  - 관리자에게 04시 I1을 우선하는 권장을 두지 않는다. 이 문서의 다른 곳(체크리스트·검증 항목·
    변경 이력)에 남은 '관리자 04시 I1 선호' 언급은 효력이 없다.
  - 04시 I1은 15-0에 따라 차단봉 철수 담당이며, 통제 A는 04시 I1에 배정하지 않는다(8-10).

8-6-1. (삭제, 2026-10-05) 04시 I1과 05~07시 일반근무자 부담의 관계 — 8-6 삭제로 함께 삭제.

8-9. 00시 이후 관리자 L3 연속 배치 강한 비권장 [소프트, 2026-09-30 추가]
  - 00시 이후(00~07시) 관리자가 연속된 두 시간 모두 L3에 배치되는 것을 강하게
    권장하지 않는다. 예: 01시 L3 → 02시 L3 비권장.
  - 하드룰과 관리자 실근무 최소 목표 다음, 일반근무자 밸런스보다 앞 순위로 적용한다.
  - 18~19시 L3 고정(6장)에는 적용하지 않는다. A 결근 시 관리자대행 준호에게 동일 적용.

8-10. 통제 A 04시 보안실 대기·I1 금지·차단봉 철수 불참 [하드, 2026-10-05 사용자 확정, 04시 I1 금지 구현 2026-10-13]
  - 통제 A는 04시에 보안실 대기로 표시하지 않는다. 04시에 휴게성 상태가 되면 '휴게'로 넣는다.
  - 통제 A는 차단봉 설치·철수에 참여하지 않는다(15-0: 04시 철수는 I1 근무자, 통제 A는 04시 I1 배정 안 함).
  - 통제 A는 04시 I1에도 배정하지 않는다(철수 날짜 규칙과 무관, FM·유도리 모두). 2026-10-13 Solver·Validator에 명시 반영.
  - 17-1의 '통제 A 04시 보안실 대기 강한 회피'와 삭제된 8-6 '04시 I1 선호'는 이 하드룰로 대체된다.
  - '통제 A'로 지정된 규칙이므로 A 결근 시 관리자대행 준호에게는 적용하지 않는다(8-8의 예외).
  - 긴급 재편성에서 04시가 이미 LOCK된 과거면 기록 그대로 둔다.

8-11. 관리자 첫 타임·막 타임 근무 없음 [하드, 2026-10-05 사용자 확정]
  - 당일 관리자(통제 A, A 결근 시 관리자대행 준호)는 평일·주말 모든 회차에서 18시와 07시에
    실제 근무를 하지 않는다(실근무 0). N1/N2 18시 L3 표기는 실제 보안실 대기라 그대로 둔다(6-1).
  - 예외: 8-3-1(N1/N3 07시 가용 일반근무자 4명)인 날은 07시 L3/I1 근무를 허용한다.
  - 긴급 재편성에서 해당 칸이 이미 LOCK된 과거면 기록 그대로 둔다.

8-12. 다음날 법정공휴일·대체공휴일만·결원 2명 관리자 마지막 2시간 휴게 [하드, 2026-10-08 사용자 확정]
  - 다음날이 법정공휴일·대체공휴일이고 결원 2명 프로필인 회차에서 당일 관리자(통제 A 또는
    관리자대행 준호)는 06시·07시 모두 '휴게' 또는 업무 없는 '보안실 대기'로 표시한다.
  - 두 칸의 실근무는 0이어야 한다. 휴게성 포스트라도 I1/G2 등 포스트 표기로 대신하지 않는다.
  - 부분가용·긴급 전환의 결원 2명 프로필에도 적용하며 LOCK된 과거 칸은 기록 그대로 둔다.
  - 주말이라는 이유만으로 적용하지 않으며 법정공휴일·대체공휴일 날짜만 기준으로 한다.

8-8. 관리자 상태에 따른 준호 신분
  - A 출근: A가 관리자이며 준호는 일반근무자와 동일하게 취급한다.
  - A 결근(준호 대행): 준호는 A와 동일한 관리자 자격으로 취급한다.
  - A 결근 시 본 장의 관리자 전용 하드룰과 선호사항을 관리자대행 준호에게
    동일하게 적용한다.
  - 따라서 A 결근 시 별도의 '준호 단독 최악 금지' 규칙은 두지 않으며,
    관리자대행 준호는 일반근무자 밸런스 비교 대상에서 제외한다.

8-13. 다음날 공휴일 관리자(통제A·준호 대행) 06시 G1 금지 [하드, 2026-10-13 사용자 확정]
  - 다음날 공휴일(토요일·일요일·법정공휴일·대체공휴일)이면 그날 관리자(통제A, A 결근·중도 인계 시 준호 관리자 대행)에게 06시 G1을 배정하지 않는다.
  - 결원 수·운영 모드와 무관하게 적용. 토·일도 포함하며 준호 관리자 대행에도 적용한다(2026-10-13 사용자 확정, 처음 '대행 제외'를 정정). 일반근무 준호에는 적용하지 않는다.
  - 긴급 재편성은 LOCK 과거 보존. 기존 8-12 결원2 관리자 06·07시 휴게 규칙도 유지한다.

제9장. 공통 피로도 및 G1/L3 운영

기본 피로도
  - 입식 실제근무 1시간 = 2점
  - 좌식 실제근무 1시간 = 1점
  - 휴게성 1시간 = 0점
  - 상층부 순찰 = 2점
  - 중층부 순찰 = 2점
  - 하층부 순찰 = 1점

  - 기본적으로 입식 2점.
  - 00,01,02,03,04시 시작 슬롯은 기본값으로 좌식 1점.
  - 유도리/FM 모두 동일.
  - 실제 현장에서는 00시보다 더 일찍 좌식 전환될 수 있다.
  - 사용자가 사전에 별도 언급하지 않으면 00~04 좌식을 기본값으로 사용한다.
  - 근무 후 실제 좌식 시작/종료를 확인하여 이력 보정한다.
  - 좌식이어도 실제 포스트 근무이며 휴게가 아니다.
  - G1 연속배정 금지 규칙은 좌식시간에도 그대로 적용한다.

9-2. L3 공통 운영
  - 기본값 입식 2점.
  - 실제 현장에서 좌식 전환이 발생할 수 있으나 이는 당일 실제운영상황에 따라
    사후 확정한다.
  - 별도 정보가 없으면 사전근무표는 L3 입식으로 계산한다.
  - L3 좌식 전환과 I1 휴게성 전환은 서로 독립된 조건이다.

제10장. 유도리 모드 전용 규칙
============================================================

10-1. 심야 I1 휴게성 전환
  - 새 생성 기본값으로 22,23,00,01,02,03시 I1을 휴게성으로 본다. 과거 저장본에 운영 설정이 없으면 종전 00~03시 기준을 보존한다.
  - 표기는 I1을 유지한다.
  - 실제 피로도 0.
  - 실제근무 0시간.
  - 실제휴게 1시간.
  - 동일포스트 연속배정 판단에서는 I1 배정으로 센다.
  - 휴게성 I1은 실제근무가 아니므로 실제 연속근무 제약의 연속시간에 포함하지
    않으며, 연속 실제근무를 끊는 휴게성 슬롯으로 본다.
  - 실제 현장에서 I1 정위치가 유지된 경우 좌식 1점/실근무 1시간으로 사후
    보정하고, 그 실제 이력에서는 좌식 실제근무로 연속근무 판정에도 포함한다.
  - 휴게성 시작은 00시보다 빨라질 수 있고 05시 시작 슬롯까지 연장될 수 있으나,
    사전지시 또는 사후 실제정보가 있을 때만 반영한다.

10-1-1. 유도리 포스트별 운영 사전지시 [2026-10-02 사용자 확정]
  - 유도리 근무표를 만들 때 포스트별로 몇 시~몇 시(끝 = 마지막 근무투입시간)를 휴게성 또는 좌식으로
    운영할지 미리 정할 수 있다. 기본값은 10-1(I1 22~03시 휴게성)이고, 지정하면 기본값을
    대신한다(지정 목록에 없는 칸은 원래 회계).
  - 고를 수 있는 운영: 남문(G2·G3)은 휴게성만, G1·L3는 좌식만, I1은 휴게성·좌식.
  - 휴게성으로 지정한 칸은 10-1·10-2의 휴게성 I1과 똑같이 취급한다: 표시상 배정 필수,
    피로도 0·실근무 0·실휴게 1, 연속근무를 끊음, 순찰 후 휴게로 인정, 동일 포스트 연속
    판단은 그 포스트로 셈, 표시상 배정도 고르게.
  - 좌식으로 지정한 칸은 좌식 1점·실근무 1시간.
  - 20시 차단봉 설치 칸(I1·남문 G2)과 04시 I1 철수 칸(10-3·10-5)은 지정과 관계없이 룰북대로 둔다.
  - 이 기준으로 피로도·실근무를 계산해 근무자 간 밸런스를 맞춘다. 지정 내용은 확정 저장 시
    근무표와 함께 저장하고 특이사항에 적는다. FM에는 적용하지 않는다.

10-2. 휴게성 I1의 표시상 배정 밸런스
  - 휴게성 I1은 실제 피로도/실근무 계산에서는 근무로 잡지 않는다.
  - 그러나 근무표상 I1 담당자는 반드시 배정한다.
  - 표시상 I1 배정은 단순히 표의 전체 포스트 투입 횟수/시간만 보는 사람이
    보았을 때 일반근무자 간 배정이 대략 비슷해 보이도록 분산한다.
  - 즉 실제 밸런스와 표시상 밸런스를 별도로 최적화한다.
  - 실제 피로도/실근무/실휴게 밸런스가 항상 우선하며, 표시상 균형 때문에 실제
    밸런스를 크게 악화시키지 않는다.

10-3. 유도리 04시 I1
  - 04시 I1은 운영상 휴게성에 가깝지만 차단봉 철수와 연결되는 특수상태다.
  - 피로도 1점.
  - 표시상 I1.
  - 실근무 1시간, 실휴게 0시간으로 집계한다.
  - 사용자 확정: 차단봉 단독업무처럼 일반 연속근무 카운트에서 제외한다. 따라서
    H-08의 전 시간대 연속 실제근무 상한 판정에는 연속근무 슬롯으로 포함하지
    않는다.
  - 동일 포스트 연속배정 판정에서는 표시상 I1 배정으로 센다.
  - 실근무 1시간과 연속근무 카운트 제외는 서로 다른 항목이다. 완전휴게로
    인정하는 것이 아니므로 해당 조건에서 순찰 후 휴게로 지정된 슬롯에는 배정할
    수 없다.
  - 차단봉 철수 1회 이력을 기록한다.
  - 단, 공통 차단봉 이력 하드룰에 따라 당일 20시 설치에 참여한 사람은 04시 I1
    철수 담당자가 될 수 없다.

10-4. 유도리 차단봉 설치 기본구조 N1/N2 + 결원 0명(일반근무자 6명 출근)
  - 20시 남문근무자 1명 + 보안실 대기 1명이 설치에 참여.

N1/N2 + 결원 1명(일반근무자 5명 출근)
  - 20시 남문 G2 근무자 1명 + 보안실 대기 1명이 설치에 참여.

N1/N2 + 결원 2명(일반근무자 4명 출근)
  - 20시 남문 미운영.

N3/N4
  - 20시 I1 담당자 + 보안실 대기 1명이 설치에 참여.

피로도 및 실근무 처리
  - 이미 실제 포스트 근무 중인 사람이 차단봉 설치를 겸임하면 차단봉 때문에
    피로도나 실근무시간을 추가 가산하지 않는다. 해당 시간의 원래 실제 포스트
    회계만 적용하고 차단봉 설치 참여 이력만 별도로 기록한다.
  - 보안실 대기 참여자는 차단봉 업무 피로도 1점, 실근무 0시간, 실휴게
    0시간으로 처리한다 (2026-10-04 개정, 11-0).
  - 차단봉만 수행한 보안실 대기 업무는 일반 포스트의 동일포스트/연속근무
    판정에 포함하지 않는다.
  - 20시 차단봉을 수행한 보안실 대기자는 식사기회로 인정한다.
  - 해당 조건에서 순찰 후 휴게로 지정된 슬롯에는 차단봉 참여 불가.
  - 설치 참여자가 2명이면 두 사람 모두 설치 참여 이력을 기록한다. 세부 이력
    제한은 제15장을 적용한다.

10-5. 유도리 04시 철수
  - 기본적으로 04시 I1 표기자가 혼자 철수한다.
  - 포스트 근무자가 철수를 겸임하면 차단봉 때문에 피로도나 실근무시간을 추가
    가산하지 않는다. 04시 I1의 원래 회계인 피로도 1점/실근무 1시간만 적용하고
    철수 이력만 별도로 기록한다.
  - 예외적으로 보안실 대기자가 철수하는 날은 차단봉 업무 피로도 1점/실근무
    0시간/실휴게 0시간으로 처리한다 (2026-10-04 개정, 11-0).
  - 공통 차단봉 이력 규칙을 반드시 적용한다.

제11장. FM 모드 전용 규칙
============================================================

11-0. 실근무 정의 [2026-10-04 사용자 확정, 이전 조항보다 우선]
  - 실근무시간은 포스트에 있는 시간과 순찰 시간만 센다.
  - 차단봉 설치·철수만 수행한 칸(보안실 대기자)은 피로도 1점, 실근무 0시간, 실휴게 0시간이다.
  - 포스트 근무자가 차단봉을 겸임한 칸은 원래 포스트 회계 그대로다(유도리 04시 I1 등).
  - 차단봉 배정 규칙(설치자·철수자 자격, 연속 설치 금지, 같은 회차 설치·철수 금지 등)과 이력은 그대로다.
  - 이미 저장된 실제 기록도 읽을 때 이 기준으로 다시 계산한다(저장 파일은 바꾸지 않는다).

11-1. I1 정상 운영 유지
  - FM에서는 심야 I1이 휴게성으로 전환되지 않는다.
  - 00시 이후에도 I1은 계속 정상 포스트로 운영한다.
  - 제6장·제7장의 공통 특수운영 시간대를 제외하면 표기된 근무자가 실제 I1
    좌식근무를 수행한다.
  - 피로도 1점/시간.
  - 실근무 1시간/시간.
  - 실휴게 0.
  - 04시 I1도 일반 정상 I1이며 차단봉 철수 담당이 아니다.

11-2. FM 차단봉 설치
  - 설치 시간은 기본 20시.
  - 오직 보안실/대기자 1명이 혼자 설치한다.
  - 남문/I1/L3/G1 등 포스트 근무자는 설치에 참여하지 않는다.
  - 설치 담당자의 차단봉 업무 피로도는 1점.
  - 실근무시간은 0시간, 실휴게도 0시간으로 기록한다 (2026-10-04 개정, 11-0).
  - 일반 포스트의 동일포스트/연속근무 제약조건에는 차단봉 업무 자체를
    카운팅하지 않는다.
  - 그러나 최적화에서는 실제근무 앞뒤 사이에 설치 업무가 끼지 않는 방향을
    선호한다.
  - 특히 설치 업무는 포스트 근무 사이에 끼는 형태를 강하게 회피한다.

11-3. FM 차단봉 철수
  - 철수 시간은 기본 04시.
  - 오직 보안실/대기자 1명이 혼자 철수한다.
  - 04시 I1 근무자는 철수에 참여하지 않는다.
  - 철수 담당자의 차단봉 업무 피로도는 1점.
  - 실근무시간은 0시간, 실휴게도 0시간으로 기록한다 (2026-10-04 개정, 11-0).
  - 일반 포스트의 동일포스트/연속근무 제약조건에는 차단봉 업무 자체를
    카운팅하지 않는다.
  - 가능하면 포스트 근무 사이에 끼지 않는 배정을 선호한다.

11-4. FM 차단봉과 순찰 후 휴게
  - 차단봉 업무가 연속근무 카운트에서는 제외되더라도 해당 조건에서 순찰 후
    휴게로 지정된 슬롯에는 절대 배정할 수 없다.

11-5. FM 결원 2명
  - 결원 2명(일반근무자 4명 출근)이면 FM 정상근무는 불가능으로 판단한다.
  - 자동으로 유도리 모드로 전환한다.

제12장. 동일 포스트 / 연속근무 하드룰
============================================================

H-01. 실제 포스트 우선 판정
  - 한 시간에 동일 인물이 포스트와 휴게/보안실에 중복표기되면 실제 수행상태를
    기준으로 판정한다.
  - 명시된 모드별 특수운영 규칙이 있으면 특수규칙이 우선한다.

H-02. 필수 포스트 정원 및 1인 1주업무
  - 운영 중인 각 포스트에는 정확히 필요한 인원을 배정한다.
  - 필수 포스트를 비워둔 채 확정하지 않는다.
  - 한 사람은 같은 시간 슬롯에 하나의 실제 주업무만 수행한다.
  - 포스트와 순찰 또는 서로 다른 포스트의 동시 실제수행은 금지한다.
  - 본 문서에서 차단봉 겸임을 명시적으로 허용한 경우만 예외다.

H-03. 동일 포스트 연속 제한과 22->23 경계
  - 18->19, 19->20, 20->21, 21->22에는 같은 사람이 같은 실제 포스트를 연속해서
    맡지 않는다.
  - 표시와 실제가 다른 시간대는 공통 특수운영 해석을 적용한다.
  - 22->23의 동일 포스트 2연속 실제배정 및 표기는 허용한다.
  - 그러나 22->23->00을 포함하여 어떤 경계에서도 같은 포스트 3연속은 금지한다.
  - 전 시간 G1 연속 금지와 명시된 관리자 특수예외를 함께 적용한다.

H-04. 심야 동일 포스트 최대 2시간 연속
  - 동일 포스트 3연속은 전 시간 경계에서 금지한다.
  - 04->05의 동일 포스트 2연속 실제배정 및 표기는 허용하되, 3연속 금지와 G1
    연속 금지는 유지한다.
  - 유도리 휴게성 I1 및 04시 I1도 표시상 I1이므로 표시상 동일 포스트 제한에는
    포함한다.

H-05. G1 연속 금지
  - 전 시간대 G1 연속배정 금지.
  - 심야 좌식 G1도 동일.

H-06. 입식/좌식 3시간 연속 회피 [강한 소프트]
  - 포스트가 달라도 실제 입식근무가 3개 시간 슬롯 연속되는 배정은 가능하면
    만들지 않는다.
  - 실제 좌식근무가 3개 시간 슬롯 연속되는 배정도 가능하면 만들지 않는다.
  - 순찰은 실제 자세 분류상 입식 실제근무로 본다. 따라서 입식 연속 여부를
    계산할 때 순찰 슬롯도 입식 1개 슬롯으로 포함한다.
  - 예: L3 입식 -> 순찰 -> G1 입식이면 실제 입식 3개 슬롯 연속으로 판정하여
    강하게 회피한다. 단, 별도의 하드룰이 적용되면 하드룰이 우선한다.
  - 위 두 경우는 하드 금지가 아니라 강한 소프트 회피사항이다.
  - 따라서 다른 하드룰 충족이나 전체 근무 밸런스를 위해 필요한 경우에는 3시간
    연속 입식 또는 3시간 연속 좌식이 발생할 수 있다.
  - 3시간 연속 실제근무가 입식/좌식이 혼합된 형태인 경우에는 이 조항만으로
    강한 회피 대상으로 보지 않는다.
  - 순찰이 포함되는 경우에는 별도의 순찰 후 휴게 규칙도 함께 적용한다.

H-06-1. 실제 휴게성 상태 4시간 이상 연속 회피 [강한 소프트]
  - 동일 근무자가 실제 휴게성 상태로 4개 시간 슬롯 이상 연속되는 배정은
    가능하면 만들지 않는다.
  - 여기서 실제 휴게성 상태는 실제 휴게, 업무 없는 보안실 대기, 유도리 모드의
    실제 휴게성 I1 등 실휴게 1시간으로 인정되는 상태를 뜻한다.
  - 실제 좌식 포스트근무, FM I1, 유도리 04시 I1 등 실근무로 회계되는 상태와 차단봉 업무
    (실근무 0·실휴게 0, 11-0)는 휴게성 연속시간에 포함하지 않는다.
  - 4시간 이상 연속 휴게는 하드 금지가 아니라 강한 소프트 회피사항이다. 순찰
    후 강제휴게, 05시 관리자 휴게, 필수 포스트/순찰 충족, 연속근무 하드룰 등
    다른 하드룰을 만족시키기 위해 필요한 경우에는 발생할 수 있다.
  - 가능한 정상해가 여러 개라면 4시간 이상 연속 휴게가 없는 해를 우선한다.
    이미 4시간 이상 연속 휴게가 불가피한 경우에는 불필요하게 더 길어지지
    않도록 최소화한다.

H-07. 05~07시 3시간 연속입식 특수조건
  - 05/06/07의 3시간 연속 입식은 금지하지 않지만 H-06에 따라 강하게 회피한다.
  - 부득이하게 05/06/07 3시간 연속 입식이 발생하는 경우에는 G2 또는 G3가 최소
    하나 포함되어야 한다.
  - 05->06, 06->07에는 동일 포스트 연속 표기를 금지한다.
  - 이 오전 구간의 동일 포스트 판정은 표시 라벨 기준이다.
  - 예: 06시 L3 -> 07시 I1이면 실제로는 둘 다 L3라도 표시 라벨이 다르므로 동일
    포스트 연속표기 제한에는 걸리지 않는다.
  - 단, 표시만 바꾸어 실제 입식/연속근무/순찰 후 휴게 제한을 피할 수는 없다.
  - 남문 연속근무라면 G2->G3처럼 다른 포스트 라벨을 사용한다.

H-08. 전 시간대 연속 실제근무 상한 [하드]
  - 모드와 출근 인원수에 관계없이 5개 시간 슬롯 연속 실제근무는 어떤 경우에도
    금지한다.
  - 순찰은 실제근무 1개 슬롯으로 카운트하며 실제 자세는 입식으로 본다. 포스트
    -> 순찰 -> 포스트처럼 업무 종류가 바뀌어도 실제근무가 이어지면 연속
    실제근무는 끊기지 않는다.
  - 특히 일반근무자 결원 1명 조건에서는 포스트/순찰/기타 연속근무 카운트 대상
    업무가 어떤 조합으로 섞여도 5개 슬롯 연속 실제근무를 절대 허용하지 않는다.
    결원 1명이라는 이유로 H-08을 완화하지 않는다.
  - 4개 시간 슬롯 연속 실제근무는 허용할 수 있으나, 그 4시간 중 최소 1시간은
    실제 좌식근무여야 한다.
  - 좌식근무로 인정되는 예: 실제 I1 좌식, 심야 좌식 G1, 실제 좌식 전환이
    확인된 L3. 순찰은 좌식시간으로 인정하지 않는다.
  - 유도리 휴게성 I1은 실제근무가 아니므로 연속근무 카운트에 포함하지 않으며
    연속 실제근무를 끊는다.
  - 실제 정위치가 확인되어 사후 좌식근무로 보정된 I1은 실제근무로 카운트한다.
  - 유도리 04시 I1 및 차단봉 단독업무처럼 본 문서에서 연속근무 카운트 제외를
    명시한 업무는 actual_work_time이 존재하더라도 이 연속근무 카운트에서는
    제외한다.
  - 하드룰을 충족한 해들 중에서는 연속 실제근무가 가급적 3시간 이내가 되도록
    선호한다.
  - 특히 3시간 연속 실제근무가 모두 입식이거나 모두 좌식인 경우에는 H-06에
    따라 강하게 회피한다.

H-09. 순찰 후 휴게
  - 원칙적으로 순찰 직후 다음 2개 슬롯은 완전휴게로 한다.
  - 결원 2명 유도리 또는 A 결근(준호 대행) + 일반근무자 결원 1명/2명
    조건에서는 제14장 H-11의 완화형 규칙을 적용한다.
  - 한 사람이 2회 순찰하는 조건에서는 그 사람의 전반부(21~23시) 순찰 직후에
    2시간 연속 완전휴게를 별도 소프트 목표로 강하게 권장하지 않는다. 전반부
    순찰 이후에는 H-06/H-08과 적용 중인 순찰 후 하드룰을 우선 준수한다.
  - 같은 2회 순찰자에게 추가로 2시간 연속 완전휴게를 줄 수 있다면, 전반부
    순찰보다 00시 이후 후반부(01~03시) 순찰 직후에 우선 배치한다. 이는 소프트
    우선순위이며 다른 하드룰보다 우선하지 않는다.
  - 차단봉 업무는 순찰 후 강제휴게 또는 완화형 규칙에서 휴게로 지정된 슬롯에
    배정할 수 없다.

H-09-1. 미리 정한 야간 반차자 [2026-10-05 사용자 확정, H-09·H-11·1576행보다 우선]
  - 대상: 근무표를 만들 때 전반부·후반부 반차로 정한 일반근무자. 긴급 반차·이탈로 빠지는
    사람은 대상이 아니다(긴급 재편성에서도 원래 표의 반차자만 대상).
  - 순찰 후 2시간 휴게(H-09)와 H-11 완화형·H-11-2는 반차자에게 하드가 아니다.
    '입식 실제근무 → 순찰 → 입식 실제근무' 금지만 유지하고, 순찰 직후 휴게는 다른 근무자
    밸런스를 다 맞춘 뒤 권장으로 준다.
  - 다른 근무자들의 밸런스를 위해 반차자의 피로도·실근무가 더 많아지는(손해 보는) 해를 허용한다.
  - [하드] 반차자는 나오는 시간 안에서 실제 휴게 합계 2시간 이상(떨어져 있어도 됨, 보안실 대기 휴게 포함).

H-13. 결원 0명 조건 관리자 심야 연속근무
  - 제8장 8-5에 따라 결원 0명 조건에서 당일 관리자의 00~05시 실제근무 3연속을
    금지한다.
  - 기존 G1 연속 금지, 입식 제한, 순찰 후 휴게, 05시 휴게와 함께 적용한다.

H-14. 평일 시작 저녁 남문 중복 및 관리자 배정 금지
  - 제5장 5-1-1에 따라 N1/N2 18~20시 G2·G3 합산 일반근무자 개인당 최대 1회,
    당일 관리자 배정 금지.

H-15. 관리자와 일반근무자의 실근무 격차
  - 제8장 8-4-1에 따라 당일 관리자와 각 출근 일반근무자의 실근무시간 차이는
    최대 2시간.

H-16. 보안실 대기 표시 정원 [하드]
  - 20시와 04시에는 모드/인원과 관계없이 보안실 표시 최소 1명을 필수로 한다.
  - 04시 보안실 표시는 정확히 1명이다. 2명 이상 표시하지 않는다.
  - 20시 보안실 표시는 최대 2명이다. 필수업무 배정 후 보안실 대기 가능 인원이
    2명 이상이면 정확히 2명, 1명만 가능하면 1명으로 표시한다. 3명 이상
    표시하지 않는다.
  - [2026-10-05 야간부터, 15-0] 20시 보안실 표시는 정확히 1명이다.
  - 20시/04시에 정원보다 남는 비포스트 인원은 휴게로 표시한다.
  - 그 외 시간은 보안실 0명을 허용한다.

H-18. 일반근무자 실근무 차이 최대 1시간 [하드, 2026-10-05 사용자 확정]
  - 그 회차 18~07시 내내 근무하는 일반근무자끼리 실근무시간 차이는 최대 1시간이다
    (2시간 이상 차이 금지). 반차·이탈 등 일부만 근무한 사람과 당일 관리자는 비교에서 뺀다.
    관리자와의 차이는 H-15(최대 2시간)를 따른다.
  - 실제 운영하는 모드의 표로 판단한다. 0-2-1의 'FM·유도리 두 기준 만족' 탐색보다 우선하며,
    두 기준 만족 표도 이 규칙을 지켜야 한다. 유도리로 다시 계산한 참고 표에는 적용하지 않는다.

H-17. 같은 포스트 한 회차 최대 3번 [하드, 2026-10-05 사용자 확정]
  - 누구든(통제 A, 관리자대행, 일반근무자) 한 회차에 같은 포스트(G1, L3, I1, G2, G3)에
    4번 이상 표시되지 않는다. 근무표 표시 기준으로 센다. 단 N1/N2 18시 관리자 L3 표기는
    실제 보안실 대기(6-1)이므로 세지 않는다(2026-10-05 사용자 확정).
    G2(1)·G2(2)는 G2로 함께 센다. 순찰·보안실 대기·휴게는 포스트가 아니다.
  - 예외: 일반근무자 2명 완전결원(출근 인원 2명 부족) 회차에서 이 규칙을 지키면 해가 없을
    때에만 그 회차에 한해 일시 해제하고, 특이사항에 해제 사실을 표시한다.
    반차 등 부분 결원으로 4명이 되는 회차는 예외가 아니다.
  - 긴급 재편성에서 LOCK된 과거에 이미 3번을 넘은 포스트는 과거를 바꾸지 않고, 미래에 그
    포스트를 더 배정하지 않는다.

제13장. 저녁 식사시간

H-10. 18/19/20시 중 최소 1시간 식사기회
  - 모든 근무자는 세 시간대 중 최소 1시간 실제 포스트/순찰에서 빠져 있어야
    한다.
  - 휴게 또는 실질적으로 식사가 가능한 보안실 대기를 식사기회로 인정.
  - 실제 포스트근무/순찰은 식사기회 불인정.
  - 좌식 포스트도 식사기회 불인정.

유도리 모드 차단봉 예외
  - 20시 보안실 대기자가 차단봉 설치에 참여해도 식사기회 자체는 인정한다.
  - 차단봉 업무로 피로도는 반영하지만(실근무는 0, 11-0) H-10 식사기회를 박탈하지 않는다.

FM 모드
  - FM 차단봉 담당자는 보안실/대기자 상태에서 차단봉을 수행한다.
  - 식사기회 인정 여부는 유도리와 동일하게 보안실 대기의 식사가능성을 기준으로
    본다.
  - 별도 당일 지시가 없으면 차단봉 때문에 식사기회를 박탈하지 않는다.

기본 순찰 6회

  - 22시 중층부 = 2점

H-11. 순찰 후 2개 슬롯 내 최소 1회 휴게 [완화형]
  - 다음 조건에서 적용한다. 1) 관리자 상태가 A 출근이고, 일반근무자 결원
    2명(4명 출근)인 유도리 모드. 2) 관리자 상태가 A 결근(준호 대행)이고,
    일반근무자 결원이 1명 또는 2명인 조건. 이 경우 모드와 관계없이 적용한다.
  - 순찰 직후 다음 2개 슬롯 중 최소 1개 슬롯은 실제 휴게성 상태여야 한다.
  - 두 슬롯 모두 연속 휴게일 필요는 없다. 나머지 1개 슬롯에는 다른 하드룰을
    만족하는 범위에서 배정을 허용한다.
  - [하드] H-11 완화형으로 순찰 후 2시간 연속 완전휴게를 보장하지 못하는
    경우라도, 순찰 직전 슬롯의 실제근무가 입식이었다면 순찰 직후 첫 슬롯은
    반드시 실제 휴게성 상태 또는 실제 좌식근무여야 한다.
  - 따라서 '입식 실제근무 -> 순찰 -> 입식 실제근무'의 연속 배정은 H-11
    완화형에서도 금지한다.
  - 순찰 직후 첫 슬롯에 업무 배정이 불가피한 경우 actual posture가 seated인
    업무만 허용한다. 단순히 표시 라벨만 좌식처럼 보이는 것으로는 충족하지
    않는다.
  - 유도리 휴게성 I1은 실제 휴게성 상태로 인정하고, 실제 정위치 I1은 좌식
    실제근무로 인정한다.
  - G1/L3 등은 해당 시간의 실제 posture가 seated로 판정되는 경우에만 순찰 직후
    허용 가능한 좌식근무로 본다.
  - 순찰 시각이 00시 이후이고 나머지 1개 슬롯에 포스트 배정이 필요하면 표시상
    I1만 허용한다. 이는 현장에서 유도리 휴게성 전환이 되지 않고 정위치
    근무하게 되는 경우에도 좌식 I1로 부담을 최소화하기 위한 규칙이다.
  - 유도리 22~03시 I1은 새 생성 기본값으로 실제 휴게성이므로 실제근무가 아니며, 그
    자체로 휴게 조건을 충족할 수 있다.
  - 실제 현장에서 I1 정위치가 확인되면 해당 슬롯은 좌식 실제근무로 사후
    보정하므로, 별도의 다른 슬롯이 실제 휴게성 상태여야 한다.
  - 유도리 04시 I1은 기존 규칙대로 실근무 1시간/피로도 1점이며 완전휴게로
    인정하지 않는다.
  - 최소 1개 휴게 조건은 실제 휴게성 여부로 판정하며 단순 표시만으로 판단하지
    않는다.
  - 순찰과 같은 시간에 다른 실제 주업무를 겸임할 수 없다.
  - 차단봉 설치/철수는 휴게로 지정된 슬롯에 배정할 수 없다.

H-11-2. 순찰 후 회복 등급 [v2.20]
  - H-11 완화형이 적용되는 날(결원 2명, 0-4-1, 0-4-2 전환 이후 등)에 적용한다.
  - 순찰한 사람마다 최소 1회의 순찰을 '보호 순찰'로 둔다. 보호 순찰에는 H-11
    완화형(직후 2슬롯 중 1회 이상 실제 휴게성, 00시 이후 순찰이면 나머지
    포스트는 표시 I1만)을 하드로 적용한다.
  - 1회 순찰자는 그 순찰이 보호 순찰이다.
  - 2회 순찰자의 나머지 1회(비보호 순찰)는 일반 입식근무와 같은 조건으로
    편성하며 일반 하드룰만 지킨다.
  - H-11-2는 2회 순찰자의 비보호 순찰에 대해 H-11 완화형의 '직후 2슬롯 내
    휴게성 1회' 조건과 '00시 이후 순찰의 나머지 포스트는 표시 I1만' 조건을
    적용하지 않는 명시적 예외다. 단, '입식 실제근무 -> 순찰 -> 입식 실제근무'
    금지는 비보호 순찰에도 유지한다.
  - 모든 순찰에서 '입식 실제근무 -> 순찰 -> 입식 실제근무'는 금지한다(H-11
    하드 유지).
  - 보호 순찰 직후 2슬롯 권장 순서 [소프트]: 1) 휴게성 2회(가장 권장), 2) 좌식
    + 휴게성(순서 무관), 3) 휴게성 + 입식(가장 낮은 권장, 순찰 직전이
    휴게성이면 입식 -> 휴게 순서 허용), 4) 2슬롯 안에 휴게성 없음(금지).
  - 2회 순찰자는 뒤(후반부) 순찰을 1)로 보호하는 것을 가장 우선하고, 어려우면
    첫 순찰을 1)로 보호하며, 그것도 어려우면 좌식이 포함된 2)를 권장한다.

H-12. 21시 상층부 관리자 고정
  - 관리자 상태가 A 출근이면 A가 21시 상층부.
  - 관리자 상태가 A 결근(준호 대행)이면 관리자대행 준호가 21시 상층부.
  - H-11 완화형 적용 조건이 아닌 경우 21시 순찰자의 22시·23시는 모두
    완전휴게다.
  - H-11 완화형 적용 조건인 경우 22시·23시 중 최소 1개 슬롯을 실제 휴게성
    상태로 보장하고, 나머지 슬롯은 H-11 규칙에 따라 배정할 수 있다.

H-12-1. 통제 A 21시 순찰 직후 근무 허용 [하드, 2026-10-05 사용자 확정]
  - 통제 A(관리자대행 아님)가 21시 상층 순찰 직전 20시에 실근무가 없으면(휴게 또는
    보안실 대기, 차단봉 설치만 한 보안실 대기 포함), 22시·23시 중 1칸은 어떤 포스트든
    배정할 수 있고 나머지 1칸은 완전휴게여야 한다.
  - 허용일 뿐 강제가 아니다. 목적은 17-4(통제 A 00시 이후 연속 휴게 2시간)를 만들기 위함이다.
  - 20시에 실근무가 있었으면 기존대로 22시·23시 모두 완전휴게다.

14-1. A 출근 + 결원 0명(일반근무자 6명 출근)
  - A는 21시 상층부를 반드시 담당하고, 순찰은 1회만 한다.
  - 일반근무자 1~6 중 5명이 각 1회씩 순찰한다.
  - 나머지 일반근무자 1명은 순찰에서 제외한다.
  - [하드] 직전 실제 야간근무에서 순찰 제외자였던 일반근무자는 다음 실제
    야간근무에서 다시 순찰 제외자로 선정할 수 없다. 즉 결원 0명 조건의 순찰
    제외자를 연속 회차에 같은 사람으로 반복하지 않는다.
  - 직전 실제 야간근무의 순찰 제외자가 여러 이유로 이번 회차에 결근한 경우에는
    그 사람을 비교대상으로 억지로 포함하지 않으며, 실제 출근자 중에서 당일
    순찰 제외자를 결정한다.
  - 이 조건에서는 누구도 2회 순찰하지 않는다.

14-2. A 출근 + 결원 1명(일반근무자 5명 출근)
  - A는 21시 상층부를 반드시 담당하고, 순찰은 1회만 한다.
  - 출근 일반근무자 5명이 각 1회씩 순찰한다.
  - 이 조건에서는 누구도 2회 순찰하지 않는다.
  - 결원 1명 조건에서도 H-08은 완화하지 않는다. 포스트와 순찰이 어떤 순서로
    섞여도 5개 슬롯 연속 실제근무는 절대 금지한다.

14-3. A 출근 + 결원 2명(일반근무자 4명 출근)
  - FM 요청도 제0-4에 따라 유도리로 자동전환하여 이 규칙을 적용한다.
  - 총 6회 순찰을 위해 A를 포함한 당일 5명 중 정확히 1명이 2회 순찰하고,
    나머지 4명은 각 1회 순찰한다.
  - 2회 순찰자는 가능하면 당일 관리자 A를 우선한다. 이는 소프트 선호이며
    하드룰, 정상해 존재 여부, 전체 밸런스 때문에 필요하면 일반근무자가 2회
    순찰할 수 있다.
  - 2회 순찰자의 한 번은 전반부(21~23시), 다른 한 번은 후반부(01~03시)에
    배치한다.
  - 같은 사람이 같은 전반부 또는 후반부에 2회 순찰하는 것은 금지한다.
  - 두 번째 순찰은 가능하면 03시 하층부를 우선한다.
  - A가 21시 상층부와 03시 하층부를 담당하는 배치를 우선 선호한다. 단, 반드시
    A가 2회 순찰해야 하는 하드룰은 아니다.
  - 2회 순찰자에게 2시간 연속 완전휴게를 추가로 배치할 수 있다면 전반부 순찰
    직후보다 00시 이후 후반부 순찰 직후를 우선한다. 전반부 순찰 직후의 2시간
    완전휴게 자체는 별도 권장 목표로 두지 않는다.

14-2-1. 부분가용 결원(0-4-1) [v2.18]
  - 순찰 6회를 반차자를 포함한 출근자에게 1인 1회로 배분한다(출근자가 7명이면
    1명은 순찰하지 않는다). A(또는 준호)는 21시 상층부를 담당한다.
  - 반차자는 자신의 가용 시간대에서만 순찰한다.
  - 누구도 2회 순찰하지 않는다.
  - 순찰 후 휴게는 H-11 완화형을 적용한다.

14-3-1. 긴급 전환 이후 순찰 [v2.20]
  - 0-4-2 전환 이후 남은 순찰은 결원 2명 규칙을 따른다. 한 사람 최대 2회,
    전반부·후반부 각 1회 이하. 밤새 가용한 사람은 최소 1회 순찰한다.
  - 2회 순찰자는 최소화하고, 필요하면 관리자(A 또는 준호)를 우선한다 [소프트].

14-4. A 결근(준호 대행) + 결원 0명(일반근무자 6명 출근)
  - 준호가 관리자대행으로 21시 상층을 담당한다.
  - 준호는 A와 동일한 관리자 자격으로 취급한다.
  - 관리자대행 준호를 제외한 나머지 5명이 각각 1회 순찰한다.
  - 추가 2회 순찰은 불필요하다.
  - 일반근무자 결원이 없으므로 원칙적인 순찰 후 2시간 완전휴게를 적용한다.

14-5. A 결근(준호 대행) + 결원 1명 또는 2명
  - 준호는 A와 동일한 관리자 자격으로 취급한다.
  - 순찰 횟수 분배는 총 6회를 충족하도록 당일 출근인원과 다른 하드룰 안에서
    결정한다.
  - 2회 순찰자가 발생하는 경우에는 가능하면 관리자대행 준호가 2회 순찰자가
    되도록 우선 선호한다. 이는 하드룰이 아니며 정상해/밸런스상 필요하면
    일반근무자가 2회 순찰할 수 있다.
  - 순찰 후 휴게는 H-11 완화형 규칙을 적용하여 다음 2개 슬롯 중 최소 1개 실제
    휴게성 슬롯을 보장한다.
  - 2회 순찰자에게 2시간 연속 완전휴게를 추가로 줄 수 있다면 전반부 순찰
    직후보다 00시 이후 후반부 순찰 직후에 우선 배치한다. 전반부 순찰 직후의
    2시간 완전휴게 자체는 별도 권장 목표로 두지 않는다.
  - 결원 1명 조건에서는 H-08의 5개 슬롯 연속 실제근무 절대금지를 어떤
    순찰/포스트 조합에서도 유지하며 이 조건으로 완화하지 않는다.
  - 준호의 추가순찰 여부는 위 관리자 우선선호와 관리자 최소부담 원칙을 함께
    보되, 하드룰과 정상해 존재 여부가 최우선이다.

14-6. 2회 순찰자 공통 소프트 우선순위
  - 당일 2회 순찰자가 필요한 경우, 관리자 상태가 A 출근이면 A, A 결근이면
    관리자대행 준호를 2회 순찰자로 우선 선호한다.
  - 관리자 2회 순찰 선호는 하드룰이 아니다. 다른 하드룰, 정상해 존재 여부,
    당일 전체 밸런스가 우선한다.
  - 동일 인물이 전반부와 후반부에 각각 1회 순찰하는 구조에서는 2시간 연속
    완전휴게를 추가로 줄 수 있을 때 후반부 순찰 직후에 먼저 배치한다.
  - 전반부 순찰 직후에는 2시간 연속 완전휴게를 별도 최적화 목표로 두지 않는다.
    다만 H-06/H-08 및 해당 조건에서 적용되는 H-11 등 하드룰은 그대로 지킨다.

14-7. 순찰 구역 회전 우선 [소프트 / 이력연계]
  - 상층부와 중층부 순찰은 각각 피로도 2점의 고부담 순찰, 하층부 순찰은 피로도
    1점의 상대적 저부담 순찰로 본다.
  - 한 직원이 직전 2회의 실제 야간근무에서 각각 순찰을 수행했고, 두 회차 모두
    하층부 순찰 없이 상층부 또는 중층부 순찰만 수행했다면, 다음 실제
    야간근무에서 그 직원에게 순찰을 배정할 때 가능한 해들 중 하층부 순찰(23시
    또는 03시)을 우선 권장한다.
  - 같은 회차에 2회 순찰을 하더라도 그중 1회라도 하층부 순찰을 실제 수행했다면
    이 조항의 하층부 배정 필요는 충족한 것으로 본다.
  - 결근, 순찰 제외, 또는 관리자 고정순찰 등으로 당일 하층부 배정의 구조적
    기회가 없는 경우에는 이 소프트룰을 미충족으로 새로 누적하지 않는다. 기존에
    누적된 미충족 우선도는 유지한다.
  - 하드룰, 관리자 고정업무, 정상해 존재 여부 및 더 높은 우선순위를 모두
    지키면서도 하층부를 배정할 수 있는 적용 가능 회차에서 다시 상층부/중층부를
    배정했다면 해당 직원의 '하층부 순찰 우선 미충족'을 1회 누적한다. 다음 적용
    가능한 야간근무에서는 하층부 배정 우선도를 이전보다 더 높인다.
  - 하층부 순찰을 실제 수행하면 해당 직원의 '하층부 순찰 우선 미충족' 누적값은
    0으로 초기화한다.
  - 이 규칙은 소프트룰이며 누적되더라도 자동으로 하드룰로 승격하지 않는다.
    하드룰을 깨서 하층부를 강제하지 않는다.

14-8. 3싸이클 순찰 구역 밸런스 [소프트 / 이력연계, 2026-09-30 추가]
  - 최근 3싸이클(실제 야간근무 6회)에서 일반근무자별로 상층·중층·하층 순찰을
    밤당 몇 번 했는지 비교하여, 이번 근무에서는 각 구역을 밤당 적게 한 사람에게
    먼저 배정한다. 결근한 밤은 분모에서 뺀다.
  - 하드룰, 순찰 인원 배분(14-1~14-5), 14-7보다 뒤 순위이며 일반 밸런스를 해치지
    않는 범위에서 적용한다.

제15장. 차단봉 공통 이력 및 회차 규칙
============================================================

15-0. 차단봉 고정 담당 [하드, 2026-10-10 사용자 정정, 2026-10-09 야간부터 · 10-4·10-5·11-2·11-3보다 우선]
  - FM·유도리 공통이다.
  - 20시 설치: G2가 운영되면 그 시간 G2 근무자 혼자 설치한다. 없으면 I1 근무자 혼자 설치한다.
    보안실 대기자는 참여하지 않는다.
  - 04시 철수: 항상 그 시간 I1 근무자 혼자 철수한다.
  - 피로도: G2 설치는 원래 입식 2점, I1 설치·철수는 원래 좌식 1점. 추가 가산 없음.
    대기자는 차단봉 피로도 없이 0점·실근무 0·실휴게 1시간이다.
    설치·철수 칸은 유도리 휴게성 변경에서 제외한다.
  - 통제 A는 설치·철수에 참여하지 않는다(8-10). 관리자대행 준호는 이 제외 대상이 아니다.
  - 같은 회차 설치자와 철수자는 달라야 한다(15-2).
  - 15-3의 대기자 연속 설치 제한은 과거 대기자 참여 이력에만 해당한다. 포스트 설치자는 제외한다.
  - 20시 보안실 대기 표시는 기존대로 1명(H-16). 대기자 참여와는 별개다.
  - 2026-10-04~08 실제 기록은 변경하지 않는다. 10/05~08은 당시 G2+대기 또는 I1+대기 설치 규칙,
    04시 I1 철수 규칙과 대기 설치자 피로도 1점·실휴게 0을 유지한다. 더 이전은 당시 규칙을 유지한다.
  - 10/09·10/10은 사용자 확인대로 대기자 설치 참여만 정정하고, 실제 포스트 인원·시간은 유지한다.

15-0-1. 차단봉 이력 집계 시작일 [2026-10-05 사용자 확정]
  - 차단봉 관련 집계는 2026-10-04 야간부터 계산한다. 10월 3일까지의 차단봉 기록은
    설치·철수 횟수, 밤당 평균(분자와 분모), 직전 담당·연속 설치 제외·역할 교대 판단,
    15-7 차단봉 배정 보정과 최근 담당 화면 집계에서 제외한다.
  - 이전 원본 근무 기록은 보존하고 순찰·피로도·실근무·휴게 집계는 기존대로 유지한다.
  - 단독 담당 규칙 15-0은 2026-10-09 야간부터 적용하며 이전 실제 이력은 당시 규칙을 보존한다.

15-1. 회차 정의
  - 차단봉 규칙에서 "같은 날", "다음날", "다음회차"는 달력 날짜가 아니라
    야간근무 회차를 기준으로 한다.
  - 야간근무 회차는 18시 출근 시작일을 기준으로 식별한다.

예시
  - 27일 18시 출근 회차의 20시 설치
  - 같은 회차의 철수는 28일 04시에 발생
  - 바로 다음 야간 회차는 28일 18시 출근 회차

15-2. 동일 회차 설치/철수 중복 금지 [하드]
  - 한 사람이 같은 야간근무 회차에 설치와 철수를 모두 담당할 수 없다.
  - 설치 참여자가 2명이면 두 사람 모두 같은 회차 철수 금지 대상이다.
  - 즉 27일 20시 설치 참여자는 같은 회차의 28일 04시 철수 불가.
  - 유도리/FM 모두 적용한다.
  - 이 규칙은 차단봉 이력 완화 시에도 자동으로 풀지 않는 하드룰이다.

15-3. 연속 회차 설치 금지 [기본 하드]
  - 설치 참여자는 바로 다음 야간근무 회차의 설치에 다시 참여할 수 없다.
  - 설치 참여자가 2명이면 원칙적으로 두 사람 모두에게 적용한다.
  - 다만 유도리 N1/N2에서 '남문근무자 + 보안실 대기자' 2명이 설치한 경우, 두
    사람 모두에게 이 규칙을 적용하면 다음 회차 정상해가 없을 때에 한해 보조
    참여자인 보안실 대기자의 '다음 회차 설치 금지'만 완화할 수 있다.
  - 이 경우 남문근무자였던 주 참여자의 다음 회차 설치 금지는 유지한다.
  - 남문근무자가 없는 설치 조합(I1 + 보안실 등)에는 이 자동완화 규칙을 임의로
    확장하지 않는다.
  - 그 다음 회차부터는 다시 설치 가능하다.

15-4. 전 회차 설치자의 다음 회차 철수 [소프트 비권장]
  - 가능하지만 가급적 피한다.
  - 예: 27일 시작 회차 설치 -> 28일 시작 다음 회차의 철수(29일 04시) 가능,
    비권장.

15-5. 전 회차 철수자의 다음 회차 설치 [소프트 비권장]
  - 가능하지만 가급적 피한다.
  - 예: 27일 시작 회차 철수(28일 04시) -> 28일 시작 다음 회차 설치(28일 20시)
    가능, 비권장.

15-6. 차단봉 이력 저장
  - 설치와 철수 이력을 별도로 저장한다.
  - 저장 기준은 실제 직원 신원 + 야간근무 회차.
  - 설치자가 복수인 유도리 회차는 설치 참여자 전원을 저장한다.
  - 최소 저장항목:
  - 회차 시작일
  - 설치 참여자 목록 및 역할(남문/포스트/보안실 등)
  - 철수 담당자
  - 모드(FM/유도리)
  - 계획/실제 구분
  - 연속회차 설치금지 완화가 발생한 경우 완화 대상/사유

15-7. 차단봉 업무와 연속근무 및 회계
  - 차단봉 단독업무는 일반 포스트의 동일포스트/연속근무 제한 카운트에 포함하지
    않는다.
  - 보안실 대기자가 차단봉만 수행하면 해당 모드 규칙에 따라 실제 피로도와
    실근무시간을 기록한다.
  - 포스트 근무자가 차단봉 설치/철수를 겸임하는 것이 명시적으로 허용된 경우,
    차단봉 때문에 피로도나 실근무시간을 중복 가산하지 않고 원래 포스트의
    회계만 적용한다. 차단봉 참여 이력은 별도로 기록한다.
  - 가능하면 실제 포스트 근무 사이에 차단봉 단독업무가 끼지 않도록 최적화한다.
    특히 설치 업무는 강하게 회피한다.
  - 순찰 후 휴게로 지정된 슬롯에는 차단봉 업무를 배정할 수 없다.

15-8. 3싸이클 차단봉 밸런스 [소프트 / 이력연계, 2026-09-30 추가]
  - 최근 3싸이클(실제 야간근무 6회)에서 일반근무자별 차단봉 설치+철수 횟수를
    밤당 기준으로 비교하여, 이번 근무의 설치·철수는 적게 한 사람에게 먼저 준다.
  - 15-2~15-5와 하드룰이 우선한다.

제16장. 마지막 휴게
============================================================

정의
  - 07시 시작 슬롯에서 일반근무자가 실제 휴게성 상태인 경우 마지막 휴게로
    본다.

인정 가능
  - 휴게
  - 업무 없는 보안실 대기
  - 유도리 모드의 실제 휴게성 I1

불인정
  - 실제 포스트근무
  - FM I1
  - N1/N3의 07시 I1은 실제 L3 입식이므로 마지막 휴게 아님.

규칙
  - 마지막 휴게자가 반드시 있어야 하는 것은 아니다.
  - 당일 관리자는 마지막 휴게 비교 대상에서 제외.
  - 직전 실제 야간근무에서 마지막 휴게였던 일반근무자는 다음 실제 야간근무에서
    다시 마지막 휴게를 받을 수 없다.
  - 직전 야간에 마지막 휴게자가 여러 명이면 모두 다음번 제외.

예외완화 순서
  - 하드룰 전체가 불가능할 경우 가장 먼저 완화 검토할 하드룰은 마지막 휴게
    연속금지이다.
  - 자동완화하지 않는다.
  - 반드시 사용자 승인 후 완화.

우선배정
  - 최근 3사이클 횟수·3:2:1 가중 방식은 폐지한다(2026-10-16 사용자 재확정).
  - 실제로 막타임 휴게를 받은 직원은 그다음 본인이 출근하는 야간근무에서 막타임 휴게 금지. 연차·결근은 다음 출근 횟수를 소비하지 않는다.
  - 그 이후 출근부터 다시 후보가 되며, 전체 저장된 실제 야간 이력에서 마지막 수혜일이 오래된 사람부터 우선한다. 저장 이력에 수혜가 없는 사람을 가장 오래 기다린 그룹으로 본다.
  - 우선순위: HARD 충족 → 마지막 수혜일 오래된 그룹부터 막타임 휴게 최대 배정 → 기존 관리자·당일/이력 밸런스 등 목표. 같은 수혜일 그룹 안에서는 기존 목표로 결정. 필수 포스트·LOCK·근무불가 등 HARD는 완화하지 않는다.
  - 07시 휴게에는 피로도 가중 선호를 중복 적용하지 않는다. 00~05시 연속휴게 선호는 기존대로 유지한다.
  - 이미 LOCK된 07시 실제 휴게는 보존한다. 화면은 고르게 나눔 자동 판정 대신 최근 수혜일 우선 기준을 표시한다.

제17장. 당일 밸런스 최적화
============================================================

기본 비교대상
  - 관리자 상태가 A 출근인 날: A를 제외한 일반근무자 전원. 준호는 일반근무자와
    동일하게 포함한다.
  - 관리자 상태가 A 결근(준호 대행)인 날: 관리자대행 준호를 제외한 출근
    일반근무자 전원.

관리자 최소부담 우선
  - 제0장·제8장에 따라 하드룰 충족 범위에서 당일 관리자의 실근무시간 최소를
    먼저 우선한다(결원 0명·1명 회차. 결원 2명 회차는 8-7에 따라 관리자 우대를
    적용하지 않는다).
  - A가 정상 관리자일 때는 A의 실근무시간이 동일한 해들 사이에서 A 개인 피로도
    최소화를 별도 관리자 우대 목표로 사용하지 않는다. 일반근무자 밸런스와 다른
    확정 소프트 목표로 해를 선택할 수 있다.
  - A 결근으로 준호가 관리자대행인 날에는 준호의 실근무시간 최소 후, 같은
    실근무시간이면 준호 개인 피로도 최소를 적용한다.
  - 아래 일반근무자 밸런스 목표는 계속 검토하고 결과를 출력한다.
  - 관리자와 일반근무자의 근무량을 똑같이 맞추는 것을 목표로 삼지 않는다.
  - 다른 미정 다목적 가중치는 임의로 만들지 않는다.

1차 실제 밸런스 목표
  1. 총피로도
  2. 입식근무 횟수/시간
  3. 좌식근무 횟수/시간
  4. 실제 포스트 횟수
  5. 실제 근무시간
  6. 실제 휴게시간
  7. 순찰 부담 및 순찰 구역 회전(최근 상/중층부 편중과 soft debt 포함)
  8. 차단봉 실제업무/이력

2차 표시상 밸런스 목표
  - 유도리 모드의 휴게성 I1을 포함한 표시상 포스트 배정시간/횟수.
  - 표만 단순 집계했을 때 특정 직원이 지나치게 적거나 많아 보이지 않도록 한다.
  - 단, 실제 밸런스보다 우선하지 않는다.

당일 목표값
  - 일반근무자 최대-최소 피로도 차이 <= 1점을 강한 목표로 한다.
  - 실휴게시간 차이 <= 1시간을 강한 목표로 한다.
  - 하드 제약상 불가능하면 더 큰 차이 허용 가능.
  - 이 경우 반드시 원인을 출력한다.

17-1. 근무자 선호 [소프트, 2026-10-02 사용자 확정]
  - 배경: 근무표를 짤 때는 그날 FM일지, 유도리를 얼마나 할지 미리 알 수 없다. 실제 근무가 지나간 뒤
    기록하면 상대적 피로도 밸런스가 무너질 수 있고, 다음 근무는 어차피 이력 밸런스로 맞춘다.
    여기에 더해 근무자들이 공통으로 선호하는 것을 손해 본 사람에게 더 끼워 준다.
  - 공통 선호:
      1) 00~05시 안에 2시간 이상 연속 실휴게가 있는 것 (없거나 적으면 싫어함)
      2) 마지막 타임(07시)이 실휴게인 것. 16장 마지막 휴게 하드룰(직전 마지막 휴게자 연속 금지)은
         그대로 지킨다.
  - 대상과 가중치: 일반근무자 모두에게 기본 가중치를 주고, 최근 3싸이클(실제 야간 6회) 실제 기록에서
    밤당 피로도가 팀 평균보다 높았던 사람일수록 가중치를 더 준다.
  - 우선순위: 하드룰 → 당일 밸런스 목표 → 이력 밸런스·3싸이클 밸런스 → 룰북의 다른 소프트룰을 모두
    맞춘 뒤 남는 선택지에서 선호를 더 많이 주는 해를 고른다. 밸런스를 깨서 선호를 주지 않는다.
  - 개인 회피 [강한 소프트]: 당일 밸런스 목표 다음, 이력 밸런스·공통 선호보다 먼저 피한다.
    하드룰·당일 밸런스 목표와 충돌하면 배정할 수 있고, 그 사실을 특이사항에 적는다.
      - 통제 A: 모든 야간 유형(N1~N4), FM·유도리에서 04시 보안실 대기를 강하게 회피한다
        (2026-10-03 사용자 확정). 실제 직원 ID A가 출근한 경우만 적용하며 관리자대행에게 전이하지 않는다.
        금지가 아닌 개인 회피 목적함수로, 기존 관리자 우대·당일 밸런스 등 상위 목적을 유지한다.
        회피하지 못한 경우 결과 특이사항에 표시한다.
      - 20시·04시를 제외한 대기/휴게 표기 횟수 균형을 새로운 강한 목표로 추가하지 않는다.
        실제 근무·휴게·피로도 계산은 기존 룰북대로 유지한다.
      - 만년: 다음날이 평일인 야간(N1 평일→평일, N3 공휴일→평일)의 06시 I1.
  - 결과 특이사항에 선호를 받은 사람과 개인 회피 반영 여부를 적는다.

17-2. 포스트 고루 배정 [최상위 권장, 2026-10-04 사용자 확정]
  - 적용: 반차·이탈 없이 출근한 일반근무자가 모두 온전히(18~07시) 근무하는 야간. 관리자·관리자대행은 제외.
    반차·이탈자가 있는 날(긴급 재편성으로 이탈이 생긴 경우 포함)은 적용하지 않는다.
  - 대상 포스트: 밤새 운영하는 G1·L3·I1. 남문(G2·G3·G2(1))은 운영 시간·인원이 적고 저녁 1인 1회
    제한(5-1-1)이 있어 제외한다. 표시 포스트 기준으로 센다(유도리 휴게성 I1도 I1).
  - 일반근무자마다 G1·L3·I1을 각각 최소 1번 배정한다. 하드룰 바로 다음 우선순위(관리자 우대보다 먼저)로
    최대한 지키며, 다른 하드룰 때문에 불가능하면 근무표는 만들고 못 선 사람·포스트와 사유를 특이사항에 적는다.
  - 포스트별 횟수 차이(최대-최소)는 당일 피로도·실휴게 목표 바로 다음 우선순위로 줄인다.

17-4. 통제 A 00시 이후 연속 휴게 2시간 [강한 권장, 2026-10-05 사용자 확정]
  - 통제 A(관리자대행 아님)는 00시 이후(00~07시)에 실제 휴게 2시간이 연속으로 붙어 있는 해를
    우선한다. 순위는 관리자 우대(A 실근무 최소) 바로 다음이며, 하드룰은 깨지 않는다.
  - 이를 위해 H-12-1로 21시 순찰 직후 22·23시 중 1칸 근무를 허용한다.

17-3. 밸런스 판정 표시 [2026-10-04 사용자 확정]
  - 근무표를 만들 때마다 온전 출근 일반근무자의 피로도·실휴게 차이를 특이사항 맨 앞(긴급 재편성 안내 다음)에 적는다.
  - 완전 n빵이 아니면 이유를 적는다: 합계를 인원으로 나눈 나머지 때문인지(정수 한계), 밸런스보다 먼저 지키는
    규칙 때문인지(계산상 최소 확인), 계산 제한시간 때문인지(더 줄어들 수 있음).
  - 업로드한 실제 기록은 수기 편성이라 프로그램이 나눈 결과가 아님을 적는다.

중요
  - 실근무시간이 같아도 입식/좌식 구성 차이가 크면 밸런스가 나쁜 것으로 본다.
  - 피로도만 맞고 입식/좌식 구성이 심하게 치우친 것도 좋은 밸런스로 보지
    않는다.
  - 표시상 균형이 실제 피로도 균형을 왜곡해서는 안 된다.

17-5. 결원 2명 조장과 일반근무자 평균 피로도 차이 [2026-10-08]
  - 결원 2명 프로필에서는 조장(관리자대행 포함)과 출근 일반근무자 평균 피로도의
    절대 차이를 4점 이내로 줄이는 강한 소프트 목표를 적용한다.
  - 필수 규칙과 앞 순위 목표, 일반근무자끼리의 밸런스를 먼저 지킨다.
  - 4점을 넘는 차이만 최소화하며, 4점 이내를 달성하면 차이를 0으로 줄이지 않는다.
  - 부분가용 및 긴급 결원 전환에도 적용한다. 저장된 실제 기록은 자동 수정하지 않는다.
  - 8-7의 기존 하드 격차 상한 미적용은 유지한다. 목표 초과 때문에 생성 자체를 막지 않는다.
  - 비고에는 조장 피로도, 일반근무자 평균, 실제 차이와 목표 충족 여부를 표시한다.

제18장. 장기 누적 이력 및 다목적 최적화
============================================================

18-1. 이력 범위
  - 최근 3개 야간 사이클.
  - 최대 6회의 실제 야간근무.

18-2. 결근 처리
  - 실제 출근한 야간만 평균/누적 비교에 포함.
  - 결근일은 0점으로 넣지 않고 제외.

18-3. 가중치
  - 최근 사이클부터 3 : 2 : 1.

18-4. 누적 항목
  - 피로도
  - 입식
  - 좌식
  - 실제 포스트 횟수
  - 표시상 포스트 횟수
  - 실제 근무시간
  - 실제 휴게시간
  - 순찰 위치/횟수
  - 최근 실제 야간근무별 상층부/중층부/하층부 순찰 이력
  - 이력연계 소프트룰별 미충족 누적값(soft debt)
  - 결원 0명 조건의 순찰 제외 여부
  - 차단봉 설치
  - 차단봉 철수
  - 마지막 휴게

18-5. 시간패턴 반복 방지
  - 새 근무표는 직전 1개 사이클의 두 야간근무와 시간패턴을 비교한다.
  - 비교항목:
  - 시간대별 포스트
  - 입식/좌식 시간
  - 순찰 시간 및 구역
  - 휴게/보안실 시간
  - 전체 근무 순서
  - 완전히 같은 패턴의 반복을 가능하면 피한다.
  - 단, 하드룰 우선.

18-6. 주간 이력 분리
  - 주간근무 이력은 야간 밸런스에 섞지 않는다.

18-7. 이력 부족
  - 3사이클 미만이면 존재하는 실제 출근 이력만 사용.
  - 사용자가 모든 이력이 없는 최초 회차로 명시한 경우 과거 차단봉/마지막
    휴게/순찰 제외/누적 밸런스/패턴 비교 이력을 만들거나 추정하지 않는다.
  - 실제로 이력이 없는 경우와 이력 확인이 되지 않은 경우는 구분한다.
  - 최초 회차에서도 당일 하드룰과 같은 회차 설치/철수 중복 금지는 그대로
    적용한다.
  - 양식 참고용으로 제공된 Excel의 과거 배정을 자동으로 실제 이력으로 수입하지
    않는다.

18-8. 소프트룰 미충족 이월 우선도 [공통]
  - 직원별 또는 회차별로 반복 여부를 실제 이력에서 판정할 수 있는 소프트룰은,
    별도 예외가 없는 한 미충족 이력을 다음 회차의 최적화 우선도에 반영한다.
  - 각 적용대상에 대해 소프트룰별 미충족 누적값(soft debt)을 별도로 관리한다.
    서로 다른 소프트룰의 누적값을 하나로 합치지 않는다.
  - 어떤 소프트룰이 실제로 적용 가능한 회차에서 충족되지 않았다면 해당 규칙의
    soft debt를 1 증가시킨다. 다음 적용 가능한 회차에서 같은 소프트룰을 다시
    위반하는 해의 불이익을 이전보다 크게 하여, 반복 위반 가능성을 낮춘다.
  - 동일 소프트룰 안에서는 직전 누적값이 큰 대상의 미충족을 더 강하게
    회피한다. 구현 시 기본 소프트 패널티에 (1 + 기존 soft debt)를 곱하는 선형
    가중을 기본값으로 사용한다. 서로 다른 종류의 소프트룰 사이의 임의 가중치는
    이 조항만으로 새로 만들지 않는다.
  - 해당 소프트룰을 충족하면 그 규칙의 soft debt는 0으로 초기화한다.
  - 결근, 순찰 제외, 구조상 대상 업무가 없는 날처럼 그 소프트룰을 충족할 기회
    자체가 없었던 회차는 미충족으로 보지 않는다. soft debt를 증가시키거나
    초기화하지 않고 그대로 유지한다.
  - 계획표가 아니라 근무 후 확정된 실제 이력을 기준으로 soft debt를 갱신한다.
    계획과 실제가 달랐다면 실제 결과를 사용한다.
  - soft debt가 커져도 소프트룰은 하드룰로 자동 승격되지 않는다. 하드룰, 모드
    규칙, 당일 특수지시, 관리자 최소부담 등 상위 우선순위를 항상 먼저 지킨다.
  - 당일에만 의미가 있고 반복 여부를 이력으로 판정할 수 없는 단발성 소프트룰은
    별도 명시가 없으면 이월하지 않는다.

18-9. 순찰 구역 회전 이력의 적용
  - 제14장 14-7의 하층부 순찰 우선은 최근 실제 야간근무의 순찰 구역 이력과
    해당 직원의 '하층부 순찰 우선 미충족' soft debt를 함께 사용한다.
  - 직전 2회의 실제 야간근무에서 모두 상층부/중층부만 순찰한 직원은 다음 적용
    가능한 회차에서 하층부 우선 후보가 된다.
  - 그 회차에서도 하층부 배정이 가능한데 상층부/중층부가 다시 배정되면 soft
    debt가 1 증가하여 다음 적용 가능한 회차의 하층부 우선도가 더 강해진다.
  - 하층부를 실제 수행하면 해당 soft debt를 0으로 초기화한다.

슬롯을 확인했는지.

자동전환 확인
  - FM 선택 + 일반근무자 결원 2명(4명 출근) -> 자동 유도리 모드 전환.

============================================================
제20장. 근무 후 실제 이력 확정 체크리스트
============================================================

다음 근무표 생성 전 직전 야간에 대해 먼저 확인한다.
  1. 유도리 모드 I1 실제 정위치/휴게성 전환 시작·종료 시간
  2. L3 실제 좌식 전환 시간
  3. G1 실제 좌식 시작·종료 시간
  4. 실제 포스트 담당자 변경
  5. 순찰 담당자 및 실제 순찰 구역 변경
  6. 결원 0명 조건에서 실제 순찰 제외자가 계획과 달라졌는지
  7. 이력연계 소프트룰의 실제 충족/미충족 결과 및 soft debt 갱신 여부
  8. 차단봉 설치/철수 담당자 변경
  9. 마지막 휴게 변경
  10. FM/유도리 모드가 실제 현장에서 변경되었는지
  11. 당일 연차/반차/조퇴 등으로 시간대별 가용성이 변경되었는지
  12. 긴급 재편성이 있었다면 LOCK된 실제근무와 재편성 후 실제 수행내용이 최종
      이력에 정확히 합쳐졌는지
  13. 기타 계획 대비 실제운영 차이

변경 없음
  - 계획표 + 해당 모드 기본 운영가정을 실제 이력으로 확정.

변경 있음
  - 실제 내용으로 시간대별 기록과 직원별 요약을 수정 후 저장.

============================================================
제21장. 검증 및 예외 처리
============================================================

21-1. OR-Tools와 독립 검증기 분리
  - CP-SAT이 근무표를 생성한다.
  - 별도의 validator가 모든 하드룰을 다시 검증한다.

21-2. 모드 오염 검증
  - FM 결과에 유도리 전용 규칙이 섞이지 않았는지 검사한다.
  - 유도리 결과에 FM 전용 제약이 잘못 강제되지 않았는지 검사한다.

21-3. 하드룰 해 없음
  - 하드룰 충족 가능한 해가 증명되지 않으면 정상표 확정 금지.
  - "수학적으로 불가능"과 "제한시간 내 해를 못 찾음"을 구분해서 보고.

21-4. FM 결원 2명
  - 일반근무자 결원 2명(4명 출근)은 별도의 infeasible 탐색 없이 정책상
    유도리로 자동전환한다.

21-5. 임시안
  - 필요 시 위반 최소 임시표를 별도로 만들 수 있다.
  - 임시표는 정상표와 명확히 구분.
  - 자동 승인 금지.
  - 어떤 규칙을 완화할지는 사용자 승인 필요.

21-6. 완화 우선순위
  - 첫 완화 검토: 마지막 휴게 연속금지.
  - 그 외 어떤 하드룰을 완화할지는 당일 사용자와 결정.

21-7. 당일 연차/반차 및 긴급 부분고정 재편성

적용 목적
  - 사전 반차 또는 근무표 확정 후 실제 근무가 시작된 상태에서 당일 연차, 반차,
    조퇴, 지각 또는 기타 갑작스러운 인원변동이 발생한 경우 사용한다.
  - 이미 수행했거나 이미 시작된 실제근무를 과거로 되돌려 수정하지 않고, 미확정
    시간대만 다시 전면 최적화한다.

LOCK 원칙 [하드]
  - 재편성 요청 시점까지 완료된 모든 시간 슬롯의 실제 수행내용은 고정값으로
    LOCK한다.
  - 재편성 요청 시점에 이미 시작되어 진행 중인 시간 슬롯도 실제 배정이 시작된
    상태라면 LOCK한다.
  - 예: 20시에 긴급 재편성을 요청했고 20시 슬롯이 이미 시작되었다면 18시,
    19시, 20시 실제 수행내용을 고정하고 21시 이후를 재편성한다.
  - LOCK 대상에는 displayed_assignment뿐 아니라 actual_post_or_work_type,
    posture_or_mode, 피로도/실근무/실휴게 회계, 순찰, 차단봉 참여 등 실제
    수행정보를 포함한다.
  - LOCK된 과거/현재 슬롯은 Solver가 변경하지 않는다.

반차 시간 경계 [확정]
  - 후반부 반차(01시 퇴근): 18시~00시 시작 슬롯까지 available, 01시 시작
    슬롯부터 unavailable.
  - 전반부 반차(01시 출근): 18시~00시 시작 슬롯은 unavailable, 01시 시작
    슬롯부터 available.
  - 반차자의 available 구간에서는 기존 룰북의 하드룰과 해당 모드 규칙을
    정상근무자와 동일하게 적용한다.
  - unavailable 슬롯은 실제근무 0시간이나 실휴게 1시간으로 계산하지 않는다.
    비교 가능한 근무기회 자체가 없는 상태다.

슬롯 중간 긴급 이탈
  - 긴급 이탈이 1시간 슬롯 도중 발생한 경우 이미 시작된 해당 슬롯은 재편성
    관점에서 LOCK한다. 다음 미시작 슬롯부터 unavailable로 처리한다.
  - 예: 22:35 실제 이탈이면 22시 시작 슬롯은 실제 수행내용으로 LOCK하고 23시
    시작 슬롯부터 unavailable로 처리한다.
  - 해당 LOCK 슬롯의 실제 수행시간이 1시간 미만이었다면 정확한 실제근무/피로도
    회계는 근무 후 실제 이력 확정 단계에서 별도로 보정할 수 있다. Solver가
    과거 슬롯을 다시 배정하지는 않는다.

연차 및 기타 긴급 이탈
  - 당일 연차자가 근무 시작 전부터 연차인 경우 해당 회차 전체를 unavailable로
    처리한다.
  - 근무 시작 후 갑작스럽게 연차/조퇴가 발생한 경우 위 LOCK 원칙에 따라 이미
    시작된 슬롯까지 고정하고 다음 미시작 슬롯부터 unavailable로 처리한다.
  - 정확한 효력 시작시각 또는 실제 이탈시각이 불명확하면 임의로 정하지 않고
    사용자 입력을 받는다.

재편성 범위
  - LOCK되지 않은 이후 시간대는 기존 계획표를 부분적으로 땜질하는 방식이
    아니라, 남은 가용 인원을 대상으로 전체를 다시 최적화한다.
  - 포스트, 순찰, 보안실, 휴게, 차단봉 및 기타 미확정 배정을 남은 시간
    전체에서 재배치할 수 있다.
  - 이때 LOCK된 실제근무까지 포함한 회차 전체의 실근무시간, 피로도, 실휴게 및
    이미 발생한 순찰/차단봉 이력을 함께 계산한다.
  - unavailable 이후 슬롯에는 어떤 실제 주업무도 배정하지 않는다.

가용시간 대비 근무부담률 및 당일 밸런스
  - 반차·조퇴·지각 등으로 가용시간이 다른 근무자는 정상근무자와 총
    실근무시간의 절대값을 직접 동일화하지 않는다.
  - 회차 내 기본 근무부담률은 실근무시간 / available 시간으로 정의한다.
    available 시간이 0인 전일 연차자는 부담률 비교 대상에서 제외한다.
  - unavailable 시간은 분모·실근무·실휴게 어디에도 넣지 않는다.
  - 기본적으로 출근 일반근무자 사이의 가용시간 대비 근무부담률 편차가 과도하게
    벌어지지 않는 해를 선호한다.
  - 다만 하드룰을 모두 지킨 상태에서 소프트룰/권장사항의 충족도를 높이기 위해
    필요한 경우 반차자의 근무부담률이 정상근무자보다 높아지는 것을 허용하며,
    소프트 미충족을 줄일 수 있다면 그러한 배치를 우선 고려할 수 있다.
  - 이는 반차자를 다른 규칙에서 예외로 취급한다는 뜻이 아니다. 반차자의
    available 구간에도 연속근무, 자세, 동일포스트, 순찰 후 휴게, 식사기회 등
    적용 가능한 모든 하드룰과 소프트룰을 동일하게 적용한다.
  - 반차자의 높은 근무부담률 자체는 규칙 위반이 아니다.
  - 하드룰과 소프트룰 충족 수준이 동일하거나 유사한 복수의 해가 있다면
    가용시간 대비 근무부담률 편차가 더 작은 해를 우선한다.

경계 제약
  - LOCK 구간과 새로 생성하는 구간의 경계에서도 동일포스트, 연속 실제근무,
    자세 연속, 순찰 후 휴게, 식사기회, 차단봉 이력 등 시간연속형 하드룰을
    이어서 판정한다.
  - 예를 들어 20시 실제 배정이 LOCK되고 21시부터 재편성할 때, 20->21 경계를 새
    회차처럼 초기화하지 않는다.
  - 이미 LOCK된 과거 사실 자체에 하드룰 위반이 존재하는 경우 Solver가 과거를
    수정할 수는 없다. Validator는 '기존 LOCK 구간에서 이미 발생한 위반'과
    '재편성으로 새로 발생한 위반'을 구분하여 보고한다.

소프트룰 처리
  - 긴급 연차/반차 재편성에서는 정상 근무표보다 일부 소프트룰 미충족이 발생할
    수 있다.
  - 하드룰을 모두 지키면서 가능한 해들 중 소프트 위반과 밸런스 악화를
    최소화한다.
  - 긴급상황이라는 이유만으로 하드룰을 자동 완화하지 않는다.
  - 하드룰을 만족하는 정상해가 없으면 21-3~21-6의 절차에 따라
    infeasible/제한시간 미탐색을 구분하고, 문서상 허용된 완화 외의 하드룰
    완화는 사용자 승인을 받는다.

다음 회차 이력 밸런스
  - 반차·조퇴·지각 회차의 절대 실근무시간만 보고 다음 회차에서 보상 또는
    추가부담을 주지 않는다.
  - 이력에는 최소한 available 시간, actual work, actual rest, fatigue,
    standing/seated, patrol/구역, barrier, 마지막 휴게, 순찰 제외, unavailable
    범위를 함께 보존한다.
  - 부분가용 회차의 부담은 실근무시간 / available 시간의 근무부담률로
    해석하되, 정상 14시간 전체가용 회차와 동일한 증거량으로 취급하지 않는다.
  - 장기 밸런스에 넘기는 부담 이력은 가용시간 비중으로 영향도를 조정한다. 기본
    개념은 정규화 부담률 × (available 시간 / 정상 전체가용시간)이며, 정상
    전체가용시간은 현행 14개 슬롯 기준 14시간이다.
  - 따라서 반차자가 7시간 available 중 5시간 근무했다면 당일 부담률은 5/7로
    높게 보지만, 다음 회차 장기 밸런스에서 14시간 전체가용 회차와 동일한
    강도로 과보상하지 않는다.
  - 순찰, 순찰구역, 차단봉, 마지막 휴게, 순찰 제외 등 실제 발생한 희소 이력은
    부분가용 여부와 무관하게 실제 발생 사실을 그대로 저장한다.
  - unavailable 때문에 애초에 받을 수 없었던 순찰/차단봉/마지막휴게 등의
    미수행을 혜택 또는 불이익으로 계산하지 않는다. '기회 없음'으로 처리한다.

Validator 및 이력
  - 재편성 결과는 LOCK 구간 + 새로 생성된 구간을 합친 회차 전체표로 독립
    Validator를 수행한다.
  - 최종 이력에는 계획표가 아니라 실제 수행내용을 저장한다.
  - unavailable 슬롯은 결근과 마찬가지로 근무 0점 또는 휴게 1시간으로 누적하지
    않고 비교기회에서 제외한다.
  - 남은 인원으로 모든 하드룰을 만족하는 해가 존재하지 않으면 억지 근무표를
    생성하지 않고 INFEASIBLE을 명확히 보고한다. 하드룰은 사용자 승인 없이 자동
    완화하지 않는다.

21-8. 긴급 재편성 INFEASIBLE 최소완화 진단 및 사용자 설명 [v2.16]

적용 목적
  - 당일 연차, 반차, 조퇴, 지각, 긴급 이탈 등으로 21-7의 정상 재편성을
    수행했으나 모든 정상 HARD를 동시에 만족하는 해가 없을 때 적용한다.
  - 목적은 HARD를 무작정 해제하는 것이 아니라, "어떤 조건을 최소한 얼마나
    예외로 인정하면 운영 가능한 표가 생기는지"를 진단하여 사용자가 이해하고
    승인할 수 있게 하는 것이다.
  - 본 절의 완화 탐색은 진단용이다. Solver가 진단 과정에서 특정 HARD를
    가상으로 완화하여 FEASIBLE 여부를 시험할 수는 있으나, 사용자 승인 없이
    실제 확정 근무표에 HARD 완화를 적용하지 않는다.

기본 원칙 1) 먼저 모든 정상 HARD를 유지한 상태로 재편성을 시도한다. 2)
INFEASIBLE이면 아래 Relaxation Ladder를 낮은 단계부터 순서대로 진단한다. 3) 더
낮은 단계의 완화만으로 해가 존재하면 더 높은 단계의 신체부담 완화를 사용하지
않는다. 4) 같은 단계에서 여러 해가 가능하면 다음 순서로 최소화한다.
  - 완화된 규칙의 종류 수
  - 예외가 적용되는 직원 수
  - 예외 시간/슬롯 수
  - 예외 발생 횟수
  - 추가되는 실제 신체부담 및 기존 밸런스 악화 5) 긴급 이탈자 본인의
    unavailable 구간에 업무를 억지로 배정하여 문제를 해결하지 않는다. 완화는
    실제로 남아 근무하는 가용 인원의 미확정 구간에서만 검토한다. 6) LOCK된
    과거/진행 중 실제 수행은 완화를 위해 변경하지 않는다. 7) 정상 INFEASIBLE과
    제한시간 내 미탐색(UNKNOWN/timeout)을 구분한다. 미탐색을 INFEASIBLE로
    단정하여 완화하지 않는다.

Relaxation Ladder

R0. 정상 재편성
  - 모든 HARD를 그대로 적용한다.
  - R0에서 FEASIBLE이면 긴급 HARD 완화는 사용하지 않는다.

R1. 과거 회차 이력 기반 공정성 제한 완화
  - 현재 회차의 안전·필수운영보다 과거 회차와의 공정한 순환을 위해 존재하는
    HARD를 우선 완화 후보로 본다.
  - 예: 직전 회차 순찰 제외자가 다음 회차에도 다시 제외되는 것을 막는 제한,
    직전 회차 마지막 휴게 수혜자의 연속 수혜 제한 등.
  - 차단봉의 과거 회차 제한은 해당 조항에 이미 명시된 완화 범위 안에서만 우선
    검토한다. 같은 회차 설치·철수 중복 금지처럼 문서가 별도로 자동완화 금지를
    명시한 조건은 R1이라는 이유만으로 풀지 않는다.
  - 의미: "최근에 같은 혜택/면제를 받은 사람이 다시 받게 될 수 있지만, 오늘의
    연속근무나 필수 포스트 보호는 그대로 유지한다."

R2. 배치형태·역할균형 제한의 최소 완화
  - 필수 인원 자체를 줄이지 않는 범위에서 동일 포스트 반복, 관리자/일반근무자
    간 절대 실근무 격차, 관리자에게만 적용되는 일부 부담분산 제한 등
    배치형태·공정성 성격의 HARD를 최소 범위에서 완화 후보로 검토한다.
  - 동일 포스트 제한을 완화할 때도 같은 포스트 3연속을 한꺼번에 허용하는
    방식보다 필요한 1개 경계의 2연속 예외처럼 더 작은 예외를 우선한다.
  - G1 연속 금지, 관리자 고정업무, 05~07 관리자 특수조건 등 개별 조항은 운영
    의미가 다르므로 "R2 전체 해제"로 처리하지 않는다. 실제로 해가 생기기 위해
    필요한 특정 조항만 진단 대상으로 선택하고 사용자에게 정확히 설명한다.
  - 의미: "필수 자리는 모두 채우되, 평소라면 피하는 반복 배치나 역할 간 균형을
    일부 희생하면 표를 만들 수 있다."

R3. 회복·휴게 배치 보호의 제한적 완화
  - R1~R2만으로 해가 없을 때 순찰 후 회복조건 등 신체부담 보호 HARD의 일부를
    필요한 최소 범위에서 검토한다.
  - 순찰 후 2시간 완전휴게 원칙 또는 H-11 완화형을 더 낮추어야 하는 경우, 어느
    직원의 어느 순찰 뒤 어떤 회복 슬롯이 줄어드는지 명시한다.
  - 가능한 경우 실제 휴게를 완전히 없애는 것보다 좌식 실제근무로 대체하는 등
    신체부담이 더 작은 예외를 우선 탐색한다.
  - '입식 실제근무 -> 순찰 -> 입식 실제근무'처럼 강한 연속부담이 새로 생기는
    완화는 같은 단계의 다른 대안보다 후순위로 둔다.
  - 의미: "순찰 뒤 평소 보장하던 회복시간 일부를 줄여야 하지만, 더 심한 장시간
    연속근무 제한은 아직 유지한다."

R4. 4시간 연속 실제근무의 좌식 포함 조건 완화 [고부담 예외]
  - R1~R3으로도 해가 없을 때만 검토한다.
  - H-08의 '4개 시간 슬롯 연속 실제근무 시 최소 1시간 실제 좌식' 조건을 특정
    직원·특정 구간에 한하여 예외 후보로 진단할 수 있다.
  - 4시간 연속근무 자체를 무제한 허용하는 것이 아니며, 필요한 최소 1회 예외만
    우선한다.
  - 실제 신체부담 증가 가능성이 큰 예외이므로 사용자 화면에서 강한 경고와 함께
    표시하고 명시적 승인을 받아야 한다.
  - 의미: "이 사람은 이 구간에서 4시간을 연속 근무하면서 평소 요구하던 좌식
    1시간을 확보하지 못한다."

R5. 5개 슬롯 연속 실제근무 금지 완화 [최후수단]
  - 모든 앞 단계로도 운영 가능한 해가 없을 때에만 진단한다.
  - H-08의 5개 슬롯 연속 실제근무 금지는 자동 적용 완화 대상이 아니다.
  - Solver는 진단 목적으로 "이 제한까지 풀면 해가 생기는지"를 확인할 수
    있으나, 실제 근무표 적용에는 반드시 명시적 사용자 승인이 필요하다.
  - 가능한 경우 5시간을 초과하여 더 긴 연속근무가 생기지 않도록 최소화하며,
    같은 해 안에서도 해당 예외 인원/횟수를 최소화한다.
  - 의미: "현재 인원으로는 누군가가 평소 금지한 5시간 연속근무를 하지 않으면
    필수운영을 맞출 수 없다."
  - R5까지 필요하면 일반적인 긴급 재편성보다 인원보강/대체인력/운영축소 등
    현장 판단이 필요한 상태임을 함께 경고한다.

절대보존 제약 [완화 금지]
  - unavailable 직원의 unavailable 시간대에 실제 업무를 배정하지 않는다.
  - LOCK된 실제 수행내역을 과거로 되돌려 변경하지 않는다.
  - 한 사람이 같은 시간에 둘 이상의 실제 주업무를 동시에 수행하게 만들지
    않는다. 룰북이 명시적으로 허용한 차단봉 겸임만 기존 규칙대로 처리한다.
  - 운영 중인 필수 포스트의 필수 정원을 임의로 비우거나 줄이지 않는다.
  - 이미 발생한 실제 순찰/차단봉/근무 이력을 삭제하거나 다른 사람의 수행으로
    바꾸지 않는다.
  - 개별 조항에서 '완화 시에도 자동으로 풀지 않는다'고 명시한 조건은 본 절의
    일반 단계보다 해당 개별 조항이 우선한다.
  - 식사기회 등 별도로 완화단계가 정의되지 않은 HARD는 본 절만을 근거로 임의
    완화하지 않는다. 추가 완화가 필요하면 사용자에게 별도 판단을 요청한다.

진단 순서 [v2.20]
  - 정상 HARD(R0) -> R1(과거 회차 이력 기반 제한만 제외) 순으로 시험한다.
  - R1으로도 해가 없으면 R1 상태를 유지한 채 R2, R3, R4, R5 규칙군을 하나씩
    단독으로 추가 완화해 시험한다(R2 단독 -> R3 단독 -> R4 단독 -> R5 단독).
  - 단독 완화로 모두 해가 없을 때에만 낮은 단계부터 누적(R2~R3, R2~R4,
    R2~R5)으로 시험한다.
  - 먼저 해가 생긴 시험의 규칙군만 사용자에게 보고한다. 예를 들어 R3 단독으로
    해가 생기면 R2+R3가 필요하다고 보고하지 않는다.
  - 어느 시험이든 UNKNOWN/timeout이면 "해가 없다고 확정되지 않음"으로 보고하고
    진단을 멈춘다.
  - 현재 구현 상태: 규칙군 단위의 단독·누적 시험까지 구현되어 있다. 아래의
    '규칙군 내부 최소 예외 조합 탐색'은 목표 명세이며, 현재는 해당 규칙군을
    완화한 해에서 실제로 발생한 예외를 보고하고 같은 사람·시간의 중복 설명을
    정리한다.

최소완화 탐색 방식
  - Solver는 R1 전체, R2 전체처럼 한 단계의 모든 규칙을 한꺼번에 OFF하지
    않는다.
  - 각 단계 안에서도 실제 INFEASIBLE을 해소하는 데 필요한 최소 예외 조합을
    탐색한다.
  - 예: 동일 포스트 제한 6건을 전부 해제하는 대신 특정 직원의 02->03 경계
    1건만 예외로 하면 FEASIBLE이라면 그 1건을 우선 제안한다.
  - 더 높은 단계의 예외 1건과 더 낮은 단계의 예외 여러 건이 경쟁하더라도
    기본적으로 단계 우선순위를 먼저 지킨다. 단, 사용자가 별도로 다른 정책을
    승인한 경우에만 변경한다.
  - 완화 진단 후에도 해가 없으면 "정의된 완화 범위에서도 해 없음"으로 보고하고
    임의의 추가 HARD를 해제하지 않는다.

사용자용 진단 설명 원칙 [중요]
  - 사용자 화면에서는 H-08, H-11, 15-3 같은 룰북 코드만 단독으로 보여주지
    않는다.
  - 룰북 코드는 개발자 상세정보나 보조표시로 둘 수 있으나, 기본 진단은 룰북을
    외우지 않은 사람도 즉시 이해할 수 있는 자연어로 설명한다.
  - 설명은 최소한 다음 네 가지를 포함한다. 1) 왜 정상표가 안 나오는지 2) 어떤
    사람의 어느 시간대가 문제인지 3) 무엇을 얼마나 예외로 인정하면 표가
    나오는지 4) 그 예외가 실제 근무자에게 어떤 의미인지
  - 정확한 원인이 Solver 결과만으로 증명되지 않는 경우 인과관계를 지어내지
    않는다. 이 경우 "현재 고정된 근무와 남은 인원으로 모든 정상조건을 동시에
    만족하는 표를 찾을 수 없음"이라고 설명하고, 최소완화 탐색에서 실제로
    FEASIBLE 전환이 확인된 예외만 제안한다.
  - 전문용어보다 현장 표현을 우선한다. 예: 'H-08 완화 필요'보다 '성호가
    02~05시 4시간 연속 근무하게 되며, 그중 좌식근무 1시간을 확보하지 못함'처럼
    표시한다.
  - 한 화면에서 먼저 요약을 보여주고, 원하면 '상세보기'에서 관련 룰북 코드와
    기술정보를 확인할 수 있게 한다.

근무를 그대로 두면 모든 정상조건을 동시에 만족하는 표를 만들 수 없습니다.

[최소 예외안]

    나머지 신체부담 규칙을 모두 지킨 표를 만들 수 있습니다.
  - 연속근무·순찰 후 휴게·필수 포스트 조건은 그대로 유지됩니다.

[선택]

  - 승인하지 않고 기존표 유지
  - 다른 인원변경 후 다시 계산

예시 B --- 신체부담 보호 완화가 필요한 경우 [정상 재편성 불가] 01시부터 인원이

  - 성호: 01시 순찰 뒤 02~03시 중 평소 확보하던 회복 슬롯 1개를 근무로

  - 5시간 연속근무 금지와 필수 포스트 조건은 유지됩니다.
  - 예외 수준: 주의 / 순찰 후 회복조건 1건

예시 C --- 높은 부담 예외 [강한 경고] 정상조건과 낮은 단계의 예외만으로는

  - 다른 직원의 5시간 연속근무는 발생하지 않습니다.
  - 예외 수준: 높음 / 신체부담 보호조건 1건
  - 사용자 승인 없이는 적용하지 않습니다.

Validator 및 기록 - 승인된 긴급예외를 포함해 생성된 표도 LOCK 구간 + 재편성 구간 전체를 Validator로 검사한다. - Validator는 다음을 구분하여 표시한다. 1) 정상 HARD 위반: 승인되지 않았으며 새 근무표에서 발생한 오류 2) 승인된 긴급예외: 사용자가 명시적으로 허용한 최소완화 3) 기존 LOCK 위반: 재편성 전에 이미 실제로 발생하여 Solver가 수정할 수 없는 사실 - 승인된 긴급예외는 일반 오류처럼 숨기지 않고 직원, 시간, 자연어 설명, 완화단계, 승인시각/승인상태를 기록한다. - 실제 근무 후 이력에는 계획상 예외가 아니라 실제 수행결과를 저장한다. - 다음 회차 밸런스에서는 긴급예외로 추가 부담을 실제 수행한 사람이 있었다면 실제 실근무/피로도/자세/순찰/휴게 이력에 그대로 반영한다.   제22장. 출력 파일 및 분석 시트

파일 1: 순수 근무표
  - 기존 현장 템플릿 형식 유지.
  - 참고 양식: 시간대가 행, G1/L3/I1/G3/G2/G2(1)/G2(2)/순찰/보안실/휴게 등이
    열인 구조.
  - 원본에 CP/과거 관리자 표기가 있어도 현재 범위와 다른 업무·인원을 자동
    추가하지 않는다.
  - 보안실은 04시에 정확히 1명만 표시한다. 20시는 1~2명만 표시하며, 필수업무
    배정 후 대기 가능 인원이 2명 이상이면 정확히 2명으로 하고 3명 이상은
    표시하지 않는다. 그 외 시간은 필요 시 0명을 허용한다.
  - 설치/철수 담당자는 짧게 식별하고, 해당 조건에 적용되는 순찰 후 휴게(원칙
    2시간 또는 H-11 완화형)를 명확히 표시한다.
  - 이전 표의 대기/휴게가 대략 기재되었더라도 그것을 새 표의 실제 회계 근거로
    그대로 사용하지 않는다.
  - 추가 색상 없음.
  - 분석용 부가정보 최소화.

파일 2: 분석 통합 워크북 시트 A. 시각화 근무표

권장 구조
  - common rule engine
  - mode profile: flexible / FM

  - OR-Tools CP-SAT solver

  - Excel exporter (openpyxl)

권장 생성 흐름

  6. 공통 하드룰 적용
  7. 모드 전용 하드룰 적용
  8. 관리자 실근무시간 최소 우선. A 출근 시 A 개인 피로도 최소는 별도 우대하지
     않고, 준호 관리자대행 시에만 동률 시 준호 피로도 최소를 적용한 후
     일반근무자 실제 밸런스 검토
  9. 표시상 밸런스 최적화
  10. 장기 이력 보정 및 soft debt 반영. 부분가용 회차는 절대근무시간이 아니라
      가용시간 정규화 부담과 가용시간 비중을 함께 반영
  11. 긴급 재편성인 경우 LOCK된 실제근무와 시간대별 availability를 적용하여
      남은 슬롯 재최적화
  12. 독립 validator 검증
  13. 사용자 최종 확인

사용자 지정 구현 순서
  1. 데이터 모델
  2. 공통 룰 엔진
  3. 유도리 모드
  4. FM 모드
  5. OR-Tools solver
  6. 독립 validator
  7. history
  8. Streamlit UI
  9. Excel export

단계별 진행 원칙

  - 초기 검증은 유도리 + N1 + 일반근무자 결원 0명(6명 출근) + A 출근부터

    사용자에게 질문한다.

v2.13에서 반영된 변경 (v2.12 대비)

  1. 순찰 구역 회전 우선 규칙 추가.

  - 직전 2회의 실제 야간근무에서 모두 하층부 없이 상층부/중층부 순찰만 수행한
    직원은 다음 적용 가능한 회차에서 하층부 순찰을 우선 권장한다.
  - 같은 회차에 하층부를 1회라도 실제 수행하면 이 요구는 충족한 것으로 본다.
  - 구조적으로 하층부 배정 기회가 없는 회차는 미충족으로 새로 누적하지 않는다.

  2. 이력연계 소프트룰의 미충족 이월 우선도(soft debt) 추가.

  - 적용 가능한 회차에서 소프트룰을 충족하지 못하면 해당 규칙의 soft debt를 1
    증가시킨다.
  - 다음 적용 가능한 회차에서는 같은 소프트룰 위반의 불이익을 더 크게 하여
    반복 위반 가능성을 낮춘다.
  - 동일 소프트룰의 기본 패널티에 (1 + 기존 soft debt)를 곱하는 선형 가중을
    기본값으로 한다.
  - 소프트룰을 충족하면 해당 debt는 0으로 초기화하며, 결근/순찰제외/구조적
    비적용 회차에서는 증가·초기화하지 않는다.
  - soft debt가 커져도 자동으로 하드룰이 되지 않으며 상위 하드룰과 정상해 존재
    여부가 항상 우선한다.
  - 계획표가 아니라 근무 후 확정된 실제 이력을 기준으로 갱신한다.

  - 일반근무자 결원 2명은 정책상 유도리 자동전환이므로 FM feasibility 대상에서
    제외.
  - A와 준호 동시 결근은 현재 프로젝트 범위에서 테스트 대상이 아니다.

  2. 남문 세부 포스트 라벨

  - 제5장에 명시된 결원 0명(6명 출근) 저녁/06시 표기 및 07시 G2·G3 표기는
    확정.
  - 결원 1명(5명 출근)의 18~20시 G2 단독 남문과 결원 2명(4명 출근)의 18시 단독
    남문은 제5장에 확정되어 있다. 06시 세부 라벨은 제5장 표기를 따른다.
  - 06시 관리자=G2와 인원수 규칙은 그대로 유지한다.

  3. 행사/의전 남문 추가

  - 당일 입력값.

  4. 실제 L3 좌식 / 유도리 I1 휴게성 / G1 조기좌식

  - 사전에는 기본값.
  - 실제 이력은 사후 확인.

  5. FM 차단봉 담당자와 식사기회의 세부 현장판정

  - 현재 기본값은 보안실/대기 상태의 식사기회를 유지하는 것으로 본다.
  - 실제 회사 FM 매뉴얼에 더 엄격한 규정이 확인되면 FM 전용규칙으로 수정한다.

  6. 관리자 최소부담 다목적 구현

  - A 출근 시 관리자 우대 목적은 A 실근무시간 최소만 적용한다. A 결근으로
    준호가 관리자대행인 경우에만 실근무시간 최소 -> 동률 시 준호 개인 피로도
    최소를 적용한다. 관리자와 출근 일반근무자 각자의 실근무시간 차이는 최대
    2시간이다.
  - 과거 시험표가 괜찮다는 평가만으로 관리자 최소부담 최적화까지 완료되었다고
    간주하지 않는다.
  - 관리자 피로도 격차는 제8장 8-4-2를 적용한다. A 출근 + 결원 0명/1명: A
    총피로도는 각 전체가용 일반근무자 이하이고 차이 하드3점 이내(정상0~2점 유지 목표는 다른 소프트 뒤, 0~3점 낮거나
    같음). 준호 관리자대행 + 결원 0명/1명: 4점 이내. 결원 2명 회차: 격차 상한
    미적용.
  - 결원 2명 회차(정식, 0-4-1, 0-4-2 전환 이후)에서 관리자 최소부담 목적함수와
    실근무 2시간 격차 상한이 적용되지 않고, 관리자 고정규칙은 유지되는지
    검증한다.

  7. 관리자 상태 및 결원 조합

  - A 출근 시 준호=일반근무자, A 결근 시 준호=A와 동일 관리자대행으로
    확정되었다.
  - A 결근(준호 대행) + 일반근무자 결원 1명/2명 조건은 H-11 완화형 순찰 후
    휴게를 적용하고 전수검증한다.
  - A와 준호 동시 결근은 현재 프로젝트 범위에서 제외한다.
  - 결원 0명 + A 출근 조건에서 직전 실제 야간의 순찰 제외자가 다음 실제 야간에
    다시 순찰 제외자로 선정되지 않는지 이력 연계 테스트한다.
  - 모든 인원/모드 조합에서 20시·04시 보안실 최소 표시를 검증한다. 04시는
    정확히 1명, 20시는 최대 2명이며 대기 가능 인원이 2명 이상일 때 정확히
    2명인지 검증한다.

  8. 새 연속근무 전역규칙

  - 모든 조합에서 5시간 연속 실제근무가 생성되지 않는지 전수검증한다.
  - 4시간 연속 실제근무가 생성되면 최소 1시간 실제 좌식이 포함되는지 검증한다.
  - 하드룰 만족해 중에서는 가능하면 3시간 이내 연속근무를 선호하도록
    목적함수를 시험한다.
  - 실제 휴게성 상태가 4시간 이상 연속되는 배정을 강하게 회피하도록 목적함수를
    시험하고, 다른 하드룰 때문에 불가피한 경우에만 허용되는지 확인한다.

  9. 차단봉 복수 설치 이력

  - 유도리의 2인 설치에서 두 참여자 이력이 모두 저장되는지 검증한다.
  - 동일회차 설치/철수 금지는 둘 모두에게 항상 적용되는지 검증한다.
  - 남문+보안실 조합의 다음회차 설치금지 완화가 정상해가 없을 때
    보조참여자에게만 적용되는지 검증한다.

  10. 순찰 구역 회전 및 soft debt 이력연계 테스트

  - 직원이 직전 2회의 실제 야간근무에서 모두 상층부/중층부만 순찰한 경우, 다음
    적용 가능한 회차에서 하층부 배정이 우선되는지 검증한다.
  - 하층부 배정이 가능한데도 다시 상층부/중층부가 배정되면 해당 soft debt가 1
    증가하고, 그 다음 적용 가능한 회차의 위반 패널티가 더 커지는지 검증한다.
  - 하층부 실제 수행 시 해당 soft debt가 0으로 초기화되는지 검증한다.
  - 결근, 순찰 제외, 관리자 고정순찰 등 구조적으로 하층부 배정 기회가 없는
    회차에서는 debt가 증가하거나 초기화되지 않는지 검증한다.
  - soft debt가 누적되어도 하드룰을 깨거나 정상해를 없애는 강제조건으로
    변환되지 않는지 검증한다.

  11. 관리자 후반부 변경 테스트

  - A 출근 조건에서 동일한 최소 실근무시간을 가진 후보해 사이에서 A 개인
    피로도 최소가 관리자 전용 tie-breaker로 작동하지 않는지 검증한다.

  - A 결근(준호 대행) 조건에서는 동일한 최소 실근무시간 후보해 사이에서 준호
    개인 피로도가 더 낮은 해를 우선하는지 검증한다.

  - 위 목적함수 변경 때문에 기존 관리자 HARD 또는 제8장 8-4-2 등 별도 제약이
    사라지지 않았는지 회귀검증한다.

  - N1/N3에서 관리자(A 또는 대행 준호)가 05시 휴게, 06시 G2를 만족하고, 07시
    가용 일반근무자가 5명 이상이면 07시 실제 휴게성 상태인지 검증한다.

  - N1/N3에서 07시 가용 일반근무자가 4명(결원 2명, 0-4-1, 0-4-2)이면 관리자가
    07시 L3 또는 I1 실제근무에 배치되는지, 5명 이상이면 07시 관리자 실제근무가
    생성되지 않는지 검증한다(8-3, 8-3-1).

  - N1~N4에서 04시 I1이 하드 또는 강한 선호로 오작동하지 않고 저우선
    소프트로만 작동하는지 검증한다.

  - 관리자 04시 I1 선호 때문에 일반근무자의 05~07시 연속 실제근무 구조가
    악화되지 않는지 검증한다.

  12. 당일 연차/반차 긴급 재편성 및 정규화 테스트

  - 20시에 긴급 반차 요청이 발생한 예시에서 18/19/20 실제 수행 슬롯이 LOCK되고
    21시 이후만 재편성되는지 검증한다.
  - 후반부 반차(01시 퇴근)는 00시 시작 슬롯까지 배정 가능하고 01시 시작
    슬롯부터 배정되지 않는지 검증한다.
  - 전반부 반차(01시 출근)는 18~00시 배정되지 않고 01시부터 배정 가능한지
    검증한다.
  - 22:35 등 슬롯 중간 긴급 이탈에서는 22시 슬롯이 LOCK되고 23시부터
    unavailable인지 검증한다.
  - LOCK 경계 전후의 동일포스트/연속근무/순찰후휴게 등 하드룰이 끊기지 않고
    이어서 판정되는지 검증한다.
  - unavailable 슬롯이 실근무 0점이나 휴게 1시간으로 잘못 누적되지 않는지
    검증한다.
  - 부분가용 근무자의 당일 밸런스가 절대 실근무시간이 아니라
    actual_work/available_time으로 비교되는지 검증한다.
  - 소프트룰 충족을 위해 반차자의 부담률이 더 높아지는 해가 허용되되,
    반차자에게 다른 하드룰이 완화되지 않는지 검증한다.
  - 다음 회차 이력에서 부분가용 회차의 부담률과 가용시간 비중이 함께 반영되고,
    절대근무시간 부족만으로 과도한 추가근무를 받지 않는지 검증한다.
  - 부분가용 회차의 실제 순찰/차단봉/마지막휴게/순찰제외 이력은 보존되고
    unavailable로 기회가 없던 미수행은 혜택/불이익으로 계산되지 않는지
    검증한다.
  - 최종 Validator가 LOCK 구간과 재편성 구간을 합친 전체표를 검사하는지
    검증한다.
  - 하드룰 정상해가 없으면 INFEASIBLE을 보고하고 자동 완화하지 않는지
    검증한다.

============================================================
최종 핵심 원칙
============================================================

  1. 근무표 작성 전에 FM/유도리 모드를 반드시 확인한다.
  2. FM에서 일반근무자 결원 2명(4명 출근)이면 자동으로 유도리 모드로 전환한다.
  3. 하드룰이 밸런스보다 우선한다.
  4. 표시근무와 실제근무를 분리해서 계산한다.
  5. 한 사람은 같은 시간 슬롯에 원칙적으로 하나의 실제 주업무만 수행하며,
     명시된 차단봉 겸임만 예외다.
  6. 피로도만 맞추지 말고 입식/좌식/실근무/실휴게까지 같이 본다.
  7. 유도리 휴게성 I1은 실제근무 0이어도 표시상 배정은 균등하게 분산하며, 실제
     연속근무를 끊는 휴게성 상태다.
  8. FM I1은 심야에도 정상 실제근무다.
  9. G1은 별도 지시가 없으면 00~04 좌식이 공통 기본값이다.
  10. 보안실은 04시에 정확히 1명만 표시한다. 20시는 1~2명만 표시하며, 필수업무
      배정 후 대기 가능 인원이 2명 이상이면 정확히 2명으로 하고 3명 이상은
      표시하지 않는다. 그 외 시간은 0명을 허용한다.
  11. 결원 0명 + A 출근 조건에서 직전 실제 야간근무의 순찰 제외자는 다음 실제
      야간근무에서 다시 순찰 제외자로 선정하지 않는다.
  12. 관리자 상태는 A 출근 / A 결근(준호 대행)으로 구분한다. A 출근 시 준호는
      일반근무자, A 결근 시 준호는 A와 동일한 관리자 자격으로 운영한다.
  13. 관리자 최소부담은 A 출근 시 실근무시간 최소만 관리자 우대 목표로
      적용한다. A 결근으로 준호가 관리자대행인 경우에는 실근무시간 최소 ->
      같은 실근무시간이면 준호 개인 피로도 최소 순으로 적용한다. 결원 2명
      회차(정식, 0-4-1, 0-4-2 전환 이후)에는 관리자 우대와 격차 상한을
      적용하지 않는다(8-7).
  14. N1/N3에서 관리자는 05시 휴게, 06시 G2, 07시 휴게를 하드룰로 적용한다.
      단, 07시 가용 일반근무자가 4명이면 07시 휴게 하드를 해제하고 관리자를
      07시 L3 또는 I1 실제근무에 배치한다(8-3-1). 관리자 04시 I1은 저우선
      소프트 권장이다.
  15. 반차·조퇴·지각의 당일 밸런스는 절대 실근무시간이 아니라 가용시간 대비
      근무부담률로 비교하며 unavailable은 비교기회에서 제외한다.
  16. 부분가용 회차의 다음 이력은 부담률과 가용시간 비중을 함께 반영하고, 실제
      발생한 희소 이력은 그대로 보존한다.
  17. 모드/인원과 관계없이 5시간 연속 실제근무는 절대 금지한다. 특히 결원
      1명에서도 어떤 포스트/순찰 조합으로도 완화하지 않는다.
  18. 4시간 연속 실제근무는 최소 1시간 실제 좌식근무를 반드시 포함한다.
  19. 순찰은 실제근무 1개 슬롯이며 실제 자세는 입식으로 계산한다. 따라서 연속
      실제근무와 입식 연속 판정에 포함한다.
  20. 가능한 해들 중에서는 연속 실제근무를 가급적 최대 3시간 이내로 배치한다.
      17-1. 실제 휴게성 상태가 4시간 이상 연속되는 배정은 강하게 회피한다.
      하드 금지는 아니며, 불가피한 경우에는 연속 휴게가 더 길어지지 않도록
      최소화한다.
  21. 동일 포스트 3연속은 금지한다. 22->23 2연속은 허용하지만 22->23->00은
      금지한다.
  22. 일반적인 순찰 후에는 다음 2시간 완전휴게를 적용한다. 결원 2명 유도리 및
      A 결근(준호 대행)+일반근무자 결원 1명/2명은 H-11 완화형 규칙을 적용한다.
      H-11 완화형에서 순찰 직전 실제근무가 입식이었다면 순찰 직후 첫 슬롯은
      반드시 실제 휴게성 또는 실제 좌식근무여야 하며, 입식->순찰->입식은
      금지한다.
  23. 2회 순찰자가 필요하면 A 또는 관리자대행 준호를 우선 선호한다. 2시간 연속
      완전휴게를 추가로 줄 수 있으면 전반부보다 00시 이후 후반부 순찰 직후에

- 2026-10-18 사용자 확정: 결원 1명인 시간은 가능하면 지킬 규칙 — 대기자 없는 시간 수를 소프트 목표 맨 앞에서 최소화한다(하드 검증 대상 아님). 원인: 결원 1명(N1 FM 결원·늦은 출근·반차·긴급)에서 순찰 후 보호 휴게(12-3)·연속 휴게(12-4) 등과 겹쳐 01·03시 등에 대기자를 둘 수 없어 표가 안 나왔음(10/18 진단).
- 결원은 해당 시간 실제 가용 인원으로 판단한다. 반차·긴급 이탈 이후 결원 2명이 되는 시간부터 이 최소 인원 하드는 제외하되, 기존 20·04시 대기 규칙은 별도로 유지한다.
- 순찰 후 보호 휴게·3시간 구간 연속 휴게2칸 등 기존 HARD를 함께 지킨다. 대기 횟수 적은 휴게 가능자를 우선하고 대기를 비워 부담 균등을 맞추지 않는다.
- 이 범위는 쉬는 사람이 1명인 FM 시간의 대기 미표기 제한보다 우선한다. 06·07시는 이 조항의 대기 필수 범위가 아니다.
- 시간 전체가 이미 LOCK된 과거 배정은 보존하며, 새 생성·긴급 재편성의 미래 구간에 적용한다. 기존 저장표 자동 변경 없음.


12-6. 통제A 제외 대기 횟수 차이 제한 [HARD, 2026-10-16 사용자 확정]
- 하루 야간 18~07시 전체 '보안실 대기' 표시 횟수를 합산한다. 20시·04시·유도리 시간도 포함한다.
- 통제A를 제외한 모든 출근자의 최다−최소를 1회 이하로 제한한다(2회 이상 차이 금지). 0회인 출근자·반차·긴급 이탈자도 비교에 포함한다. 통제A 결근 시 준호 대행은 통제A 자체가 아니므로 비교에 포함한다.
- 이를 맞추기 위해 통제A의 업무 없는 휴게 칸을 보안실 대기로 표기할 수 있다. 통제A는 대기부담 균등 목표의 비교·비용에서도 제외한다. 04시 통제A 대기 금지·필수 포스트·순찰 후 보호 휴게 등 다른 HARD를 해제하지 않는다.
- 18~05시 대기 최소1명(12-5)·연속 휴게 표시(12-3/12-4)와 함께 적용한다. LOCK된 과거는 바꾸지 않는다. 동시 충족이 불가능하면 임의 완화하지 않는다.
- 기존 저장표는 자동 변경하지 않으며 새 생성·재편성·미저장 수정 검증에 적용한다.


8-14. 통제A I1 최소 배정 [HARD, 2026-10-16 사용자 확정]

- 기존 대기·순찰·휴게·포스트 HARD와 함께 적용하며 기존 저장표 자동 변경 없음.
