- T/O: 주간고정 11, A·B·C조 각 10(보안 7 + CP 3), 안내 5, 주차 3. 결원 = T/O − 그날 명단 인원.
- 조 교대(6일 주기, A조 달력 `calendar_info.shift_kind`): A 주간 → 야간 B·휴무 C / A 야간 → 주간 C·휴무 B / A 휴무 → 주간 B·야간 C.
- 사고 = 결원 + 출근 안 한 사람(연차·휴가·병가·결근·대휴·휴무·훈련·경조사). 반차·교육·검진·입사·퇴사는 비고만(출근). 지원·대근은 원래 소속에서 출근(받는 조는 그대로).
- 주말·공휴일: 주간고정·안내·주차 전원 사고(지원·대근·교육으로 나온 사람만 현인원). 휴무조 전원 사고(나온 사람은 뺌).
- 현인원·계·소계·합계: 원본 수식 그대로(계 = 주간고정+주간조, 소계 = 계+야간+휴무, 합계 = 소계+안내+주차).
- 비고 표기: `종류 N명(이름, 이름)`, 순서 결원→연차→휴가→대휴·휴무→훈련·경조사→반차→교육→지원·대근→입사→퇴사. 이름은 명단 순서, 최찬우는 '이사님'. 하계휴가→'휴가', 예비군→'훈련', 야간 전반부 반차→'전반야 반차', 후반부→'반차', 입사+주간교육→'입사 및 주간교육'. 주차는 직책(소속 D조여도 주차 칸).
- 작성자 = 전날 밤 야간조 조장(D일 일보는 D-1 야간 근무 중 작성). 조장이 빠진 날은 대행(최정식·선임).

**원본 구조** (평일 65×61, 주말 56×36, 수식 없음)
- 1행 `적용일자 | 2026.09.22(화) ~ 익일 07:00 | 보안팀 근무 명령서`, 2행 작성자.
- 주간(4~45행): 4행 시간(06~19, 시간당 30/60 두 칸, col = 7 + 2×(시−6)). 6행~ B=보안, C=이름, D=직책, E=POST. **이름 목록과 POST 줄은 독립.** 이름: 주간 출근 주간고정 → 주간조 통제 → 대원(1)~(n), 대원(n) = 편성표 번호 n. POST 줄(평일): G1·G2·G3·4C·L1·L2·C1·C2·CP·셔틀·1C·지하층 순찰·대기·휴게실·4층(I1).
- 24~26 CP 이름, 29~33 안내(고정 틀), 34 사고내용(F)·팀장공지(S, 고정 4줄), 36~38 화물주차장 이름, 오른쪽 주차 2·3·4인 틀, 45 `計 | N | ○ 근무인원: N명`.
- 야간(46~61행): 46행 시간(18~07, col = 7 + 2×((시−18)%24)), 이름(통제 + 대원 = 야간 번호), POST CP·G1·L3·I1·G3·G2·G2(1)·G2(2), 순회/셔틀·순찰·휴게실·보안실, 61 `計 | N | ○ 근무인원: N명 ○연차 …` = 일보 야간조 줄.
- 주말: 주간고정·안내·주차 없음(지원자만), POST G1·G2·G3·I1·L1·CP·순찰·휴게실·보안실, 행 번호 다름.
- 편성표 → 시간표 옮기기: 셔틀 `5(해지)`·`4(설치)` 안 적음, `CS교육:`·`교육:` 떼고 번호만, 4층(I1)은 안내 고정 틀. 원본 세로 병합 칸에 다른 POST 값이 들어가면 POST별 줄로 함께 적는다. 시간표 칸은 1시간 단위 병합 + 얇은 검정 테두리.

**사고내용 문장**
```
○ 보안 :  - 주간조: C조 / 야간조: A조
            - 근무인원: 16명 / 휴무인원: 10명
            - 결원 2명, 연차 1명(…)
            - 야간조 지원 1명(최정식)        ← 출근자 비고(지원·반차·교육)는 다음 줄
○ CP : - 근무인원: 3명, 연차 1명(김준하)
○ 안내 : - 근무인원: 5명, 오후반차 1명(유민)   ← 주말은 '휴무 5명'
○ 주차 : - 근무인원: 2명, 연차 1명(이정민)     ← 주말은 '휴무 3명'
```
- **보안 근무인원(10/13 확정)** = 주간고정 출근 + 주간조 출근 − CP + 다른 조 출근자(야간조 주간교육·주간지원, 휴무조 출근). CP는 넣지 않는다(주말도). 야간지원 간 사람도 출근이라 빼지 않는다. `security_order.security_adjust`.
- 휴무인원 = 휴무조 출근 안 한 인원(결원 제외, 주말은 주간고정 휴무 포함). 결원은 합쳐 맨 앞, 같은 종류 한 묶음, '이사님' 제거, 야간지원→'야간조 지원', 예비군 훈련→'훈련'.
- 計 = 보안 + CP + 안내 + 주차. 야간 근무인원 = 일보 야간조 현인원.
- 원본 7/1~9/22 84일 대조: 52일 일치. 차이는 주말에 CP를 보안에 넣은 날 12일(우리 기준은 안 넣음), 원본 계산 실수, 반차·교대조·야간지원을 작성자마다 다르게 센 날 — 규칙 하나로 맞출 수 없어 위 기준으로 확정.

**CP 시간표 틀** (실제 형태는 올린 엑셀의 같은 인원 날짜 우선, `cp_schedule.standard_pattern`)
