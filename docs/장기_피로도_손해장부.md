# 장기 피로도 손해 장부

2026-10-20 사용자 승인 구현. 집계 시작일은 **2026-10-04 포함**이다.

## 집계

- 각 확정 실제 기록의 온전 출근 일반근무자만 비교한다. 관리자·관리자 대행·반차·긴급 이탈·결근은 제외한다. 주말 신규자 예외 대상도 제외한다.
- 당일 손해 = 본인 실제 피로도 − 같은 날 비교 대상 평균. 비교 대상이 2명 미만이면 그날은 적립하지 않는다.
- 이름으로 연결하며, 표시 번호가 바뀌어도 같은 사람의 잔액을 이어간다. 동명이인은 별도 고정 식별자 도입 전 지원 범위 밖이다.
- 양수는 더 맡은 미상환 부담, 음수는 상대적으로 덜 맡은 부담이다. 소수는 유리수로 누적하고 화면만 소수 둘째 자리로 표시한다.
- 야간과 주말 주간은 각각 자기 저장소의 실제 기록만 읽는다. 평일 주간은 이번 대상이 아니다.
- 월말·최근 4회·최근 6회 기준으로 지우지 않는다. 10/04 이후 전체 기록을 읽고, 편성일 이전 기록만 Solver에 준다. 과거 날짜의 편성에 미래 기록을 섞지 않는다.
- 후보 생성·재생성·미리보기는 저장하지 않는다. 같은 날짜를 여러 번 저장해도 한 번만 집계하며, 실제 수정·삭제·복구 때 잔액은 원본에서 다시 계산한다. 손상 기록은 조용히 빼지 않고 오류로 알린다.

- (2026-10-20 사용자 확정) 야간 하루 종일 준호 대행(A 결근) 날은 대행 준호도 적립한다. 그날 온전 출근 일반근무자
  평균과 비교만 하고 평균 계산에는 넣지 않는다. 반차 교대(승계)일의 준호는 종전대로 제외.

## 편성

- (2026-10-20 사용자 확정 (가)) 순서: 필수규칙 → 가능하면 지킬 규칙(긴급 회복·결원 1명 대기 등) → 막타임 →
  차단봉 → 하층 순찰 순번 → 당일 균형 → 장기 장부 → 기타 목표. 야간 룰북 0-6, 주말 룰북 §5.

필수규칙과 LOCK을 유지하고 당일 피로도·휴게 균형을 맞춘 뒤, 현재 근무자들의 예상 누적 잔액 중 가장 큰 양수 부담을 먼저 줄인다. 이어 전체 잔액 제곱합을 줄여 부담 편차를 줄인다. 기타 개인 선호와 최근 이력 목표보다 앞에서 적용한다. 잔액 차이 1점 미만도 대상이다.

예상 잔액 = 기존 잔액 + 이번 배정 피로도 − 이번 온전 출근 일반근무자 평균.

HARD를 바꾸거나 같은 제약 함수를 Solver와 Validator가 공유하지 않는다. 손해가 크다고 당일 균형을 깨거나 강제로 상환하지 않으며, 제한시간 안의 최선 후보를 사용한다. 시간이 부족하면 항상 최적 상환이 보장되는 것은 아니다.

야간의 실제 저장소를 통한 편성에서는 종전 17-6의 최근 4회 최고·최저 평균 차이 1점 발동 보상 대신 이 장부를 사용한다. 기존 최근 4회·최근 6회 통계와 기타 순찰·차단봉 이력은 계속 유지한다. 주말 긴급은 피로도 격차 1 이내를 먼저 찾고, 불가능이 확인된 때만 2 이내로 넘어가는 기존 절차를 유지한다.

## 화면

근무표 후보·저장표·긴급 재편성·업로드 확인표의 공통 화면에 이전 잔액, 이 표의 증감, 적용 후 예상 잔액과 선택일까지의 실제 저장 잔액을 표시한다. 후보 예상과 실제 잔액을 구분하고, 월평균·최근 3싸이클 평균을 보상 잔액으로 부르지 않는다. PC는 표, 휴대폰은 사람별 줄로 표시한다.

계산 기준이 바뀌면 기존 원본을 새 계산 기준으로 읽은 결과도 바뀔 수 있다. 이번 구현은 원본에 저장된 실제 피로도와 실제 수정 이력을 읽으며, 과거 표를 새 Solver로 재편성하거나 덮어쓰지 않는다.
