## 1. 적용 범위

- 주말·공휴일 주간 08:00~18:00, 1시간 단위 10칸. A조 주간인 주말·공휴일 날짜.
- 일반근무자 정원 6명 + 통제A 1명. 일반근무자 결원 0·1·2명.
- 미리 정한 반차(§8-0)와 긴급 반차·이탈(§8-1)을 지원한다.
- 평일 주간·야간 룰북과 구분한다. 야간 규칙을 자동으로 가져오지 않는다. 주말 기록은 평일·야간 월간 집계에 섞지 않는다.
- 지원하지 않음(수기 편성): 통제A 결근·관리자대행, 일반근무자가 3명 이하로 남는 시간.

## 2. FM·유도리의 표시와 실제 계산

같은 표시표를 두 기준으로 각각 계산한다. FM/유도리 전환은 G2의 실제 운영만 바꾼다.

- FM으로 생성하면 같은 표시표가 FM·유도리 양쪽의 하드룰과 밸런스를 모두 만족해야 한다. 주 표시표와 저장 모드는 FM, 유도리는 같은 배정을 환산해 따로 검증한다.
- 두 기준을 함께 만족하는 해가 없으면 FM만으로 바꾸거나 규칙을 완화하지 않고 '해 없음'으로 표시한다.
- 유도리를 직접 고르면 유도리 기준만 적용한다.

| 표시 | FM 실제 상태 | FM 실근무/피로도/실휴게 | 유도리 실제 상태 | 유도리 실근무/피로도/실휴게 |
|---|---|---|---|---|
| G1 | 입식 | 1시간 / 2점 / 0시간 | 입식 | 1시간 / 2점 / 0시간 |
| G2 | 입식 | 1시간 / 2점 / 0시간 | 휴게성 | 0시간 / 0점 / 1시간 |
| I1 | 좌식 데스크 | 1시간 / 1점 / 0시간 | 좌식 데스크 | 1시간 / 1점 / 0시간 |
| L1 | 입식 | 1시간 / 2점 / 0시간 | 입식 | 1시간 / 2점 / 0시간 |
| 순찰 | 입식 실근무 | 1시간 / 구역별 / 0시간 | 입식 실근무 | 1시간 / 구역별 / 0시간 |
| 휴게 | 휴게 | 0시간 / 0점 / 1시간 | 휴게 | 0시간 / 0점 / 1시간 |

순찰 피로도: 상층·중층 2점, 하층 1점(§4).

## 3. 결원별 운영 포스트

| 일반 결원 | 일반 인원 | 통제 포함 인원 | 운영 |
|---|---:|---:|---|
| 0명 | 6명 | 7명 | G1·G2·I1·L1 각 1명 |
| 1명 | 5명 | 6명 | G1·G2·I1·L1 각 1명 |
| 2명 | 4명 | 5명 | G1·I1·L1 각 1명, G2 미운영 |

- 열린 포스트는 매시간 정확히 1명, 한 사람이 같은 시간 두 업무를 겸하지 않는다.
- [하드] G2가 열린 날은 통제A 포함 누구나 G2 하루 최대 2회.
- [하드] 일반근무자는 그날 운영하는 포스트를 각각 최소 1번 선다(통제A는 §7 별도).
- [강한 비권장] 같은 포스트 2연속. 하드룰과 밸런스 다음 순위로 최소화.
- G1·I1·L1 횟수 상한은 두지 않는다.
- 화면의 G2 '미운영'은 규칙상 미운영 시간(일반근무자 4명 이하)만 표시한다. 업로드 원본에서 비어 있는 G2는 빈칸 그대로.

## 4. 순찰

- 운영 시간: 09~10·10~11·11~12·14~15·15~16·16~17, 총 6회.
- 구역·피로도: 09 상층 2점, 10 중층 2점, 11 하층 1점, 14 상층 2점, 15 중층 2점, 16 하층 1점.
- 결원 0명: 통제A 1회, 일반 6명 중 5명이 각 1회. 결원 1명: 통제A 1회, 일반 5명 각 1회. 결원 2명: 통제A 2회, 일반 4명 각 1회.
- [하드] 첫 순찰(09시 상층)은 항상 통제A(§7).
- 순찰은 실근무·연속 입식 판단에 포함한다.

## 5. 밸런스

- 통제A를 제외한 전일 일반근무자끼리 비교한다.
- [하드] FM·유도리 각각 실근무 최대−최소 ≤1시간, 피로도 최대−최소 ≤1점. 해가 없으면 자동 완화하지 않는다(해 없음).
- 완벽한 n빵(차이 0)을 먼저 찾고, 불가능할 때만 차이 1 이내에서 차이 합이 가장 작은 표. 화면에 '완벽한 n빵' / '1 차이 표(불가능 확인)' 표시.
- [소프트] 이력 어드밴티지: 완벽한 n빵이 안 되는 날 남는 피로도 차이는 최근 주말 주간 저장본 4회(평일·야간 제외)에서 손해 본 사람(그날 일반근무자 평균보다 피로도를 많이 한 합)이 덜 받는다. 순위: n빵 차이 최소 → 같은 포스트 2연속 최소 → 이력 어드밴티지. 반차·긴급 재편성도 같은 순위.
- 실휴게 차이는 별도 기준을 두지 않는다(실근무 차이로 함께 맞춰짐).

## 6. 연속근무

- [하드] 3연속 입식 금지. FM은 G1·G2·L1·순찰, 유도리는 G1·L1·순찰을 입식으로 센다.
- [하드] 결원 0·2명 시간은 최대 3연속 실근무, 결원 1명 시간은 최대 4연속(5연속 금지). FM·유도리 각각.
- 결원 1명 시간의 4연속은 4연속 없이 해가 없을 때만 쓰고, 그때도 횟수를 최소로(완벽 n빵보다 우선). 화면 '🔁 4연속 실근무 N건'. 현재 규칙에서 결원 1명 FM은 최소 6건.
- [하드] 4연속 실근무가 생기면 그 4칸에 G2·I1이 각각 최소 1번(3연속 입식 금지 유지). 유도리 기준은 G2가 휴게성이라 4연속 자체가 생기지 않는다. (2026-10-18 사용자 확정)
- 유도리 G2와 휴게·대기는 연속 실근무·입식을 끊는다. I1은 실근무를 끊지 않지만 입식 연속은 끊는다.
- [하드] 통제A 포함 전 근무자 휴게·대기만으로 3연속 금지. 유도리 G2 휴게성이 끼면 3연속 허용, 4연속 휴게(G2 포함)는 금지. (2026-10-18 사용자 확정, 종전 'G2 포함 3연속 금지' 완화)
- [강한 권장] 15·16·17시 3연속 근무로 끝나는 사람이 한 명이라도 있으면, 통제A를 뺀 누구도 16·17시 2연속 휴게(대기 포함)가 나오지 않게. 순위: 통제A 16시 휴게·통제A 피로도 다음, 4연속 최소·완벽 n빵 판정 전. (2026-10-18 사용자 요청)

## 6-1. 보안실 대기 (2026-10-18 사용자 확정)

- 대기 = 실휴게·피로도 0(휴게와 같은 회계). 표·현장 양식의 '대기' 열.
- [하드] 매시간 대기자 정확히 1명(더도 덜도 아니게). 결원 수와 무관.
- [하드] 순찰 직후 1시간이 쉬는 시간이면 휴게로 표기(대기 금지). 그 밖의 휴게/대기 배치는 제한 없음.
- [하드] 통제A를 뺀 근무자끼리 하루 대기 횟수 차이 ≤1(반차·이탈자 포함).
- [비권장] 통제A 대기는 근무자끼리 차이 1을 넘길 때만. 08시(휴게·G2)·17시(휴게)는 대기 아님.
- 10/18 이전 저장본·업로드 표(대기 없이 휴게로 기록)에는 대기 규칙을 적용하지 않는다(standby 표시가 있는 표만).

## 6-2. 막타임(17시) 휴게 — 야간 07시와 이어서 (2026-10-18 사용자 확정)

- 막타임 = 17시 실휴게(휴게·대기, 유도리 표는 G2 휴게성 포함). 이력은 저장된 야간(07시 실휴게)과 빨간날 주간(17시)을 시간순으로 이어서 본다(같은 날은 주간이 먼저).
- [하드] 직전 실제 출근(야간이든 빨간날 주간이든)에 막타임을 받은 일반근무자는 17시 실휴게 금지. LOCK된 17시는 보존.
- [우선] 나머지는 마지막 수혜가 오래된 사람부터(한 번도 안 받은 사람 맨 앞). 통제A 16시 휴게 다음 순위, 통제A 피로도·완벽 n빵 판정 전.
- FM 표 17시 G2(유도리로 운영하면 휴게성 막타임, 2026-10-18 사용자 확정): ① [아주 강한 권장] 직전 출근 막타임 수혜자는 17시 G2에도 넣지 않음 ② [우선] 실제 휴게·대기 순번 다음으로 오래된 사람부터. 지키기 어려우면 다른 규칙 우선.
- 지난 빨간날 주간 FM 표의 실제 유도리 운영 여부: 근무표 화면 맨 위 배너(최근 14일, 최대 3개)·그 날짜 저장본 '이날 실제 운영'에서 선택. **고르지 않으면 유도리 했음**. 유도리였던 날은 17시 G2도 막타임 수혜로 이력에 넣는다(다음 근무표 직전 수혜·순번에 반영). 기록 history/weekend_day/flex_actual.json.
- 막타임 표: FM 표 17시 G2는 '🛌(유도리)'로 상시 표시(이번 표는 항상, 지난날은 실제 유도리 운영일 때만).
- 야간 엔진은 아직 주말 17시를 이력에 넣지 않는다(10/18 사용자 선택 ①: 주말 엔진만).
- 비고 '막타임 휴게' 표: 야간+빨간날 주간 최근 6근무, 빨간날 주간 칸 노란 배경.

## 7. 통제A

- 통제A도 포스트·순찰에 배정한다.
- [하드] FM·유도리 각각 통제A 실근무는 어느 일반근무자보다도 많지 않다.
- [하드] 09시 첫 순찰은 통제A.
- [하드] 운영 포스트(G1·G2·I1·L1, 결원 2명 시간이 있으면 G2 제외)를 하루 최소 1번씩.
- [강한 권장] 16시는 휴게(마지막 2시간 휴게). 휴게가 안 되면 G2 우선, 그다음 다른 업무. 평소에는 다른 소프트 목표보다 먼저 맞추고, 긴급 재편성은 가능하면 지킬 규칙 다음 순위. (2026-10-16 사용자 확정, 종전 '16시 G2만' 하드 폐지)
- [하드] 08시(첫 시간)는 휴게·G2만. LOCK된 칸은 보존. (2026-10-16 사용자 확정)
- 통제A 피로도(표의 운영 기준 — FM 표는 FM 피로도, 끝까지 근무하는 일반근무자 각각과 비교, 2026-10-18 사용자 확정):
  - [하드] 결원 1·2명: 최소 1점 적게.
  - [하드] 결원 0명: 가장 적게 받은 근무자보다 많지 않게. [강한 권장] 최소 1점 적게(FM·유도리 동시 만족 안에서, 결원 0명 FM은 다른 하드룰로 1점 차이가 안 되는 날이 있음).
  - 상한 없음. 순위: 16시 휴게 다음, 완벽 n빵 판정보다 먼저. 반차·긴급일은 권장만(반차자 휴게 1시간 다음).
- [하드] G1 최소 1번은 11~15시 안. [비권장] 그 밖의 시간 G1. (2026-10-18 사용자 확정)
- [권장] 통제A에게 피로도 2점 업무를 더 줄 때는 L1 우선(G1·FM G2·상/중층 순찰 횟수 최소). 같은 포스트 2연속 다음 순위. (2026-10-18)
- [하드] 16시가 결원 2명(G2 미운영) 시간이면 G1 금지. (이때 다른 하드룰로 휴게가 불가능해 I1·L1·순찰 중 배정됨, 10/16 확인)
- [하드] 17시(마지막 시간)는 휴게.
- 통제A의 G2도 하루 최대 2회에 포함한다.
- 긴급 재편성·해 없는 반차일에는 09시 순찰·포스트 1번씩을 '가능하면 지킬 규칙'으로 둔다. LOCK으로 지난 칸은 보존한다.
- 통제E가 통제 자리에 지원 온 날은 통제E가 통제A 자리를 맡는다(이름표 '통제E(지원)').

## 7-1. 통제A 미리 정한 반차·연차 — 준호 대행 (2026-10-18 사용자 확정, 긴급 반차는 아직 미지원)

- 화면 '통제A 상태'(연차일정이 기본값): 출근 / 오전반차 / 오후반차 / 연차(준호 대행). 대행 준호가 하루 전체 출근이 아니면 수기 편성.
- 통제A가 빠진 시간은 그 시간 인원이 1명 적으므로 결원 1명 더로 센다 → 평소 결원 규칙 그대로(결원 2명 시간 G2 미운영, 결원 1명 시간 4연속 허용 등).
- **오전반차**(08~12 없음, 13시 출근): 08~12시는 준호가 통제A 패턴 — 08시 휴게·G2(하드), 09시 G1 금지(첫 순찰 규칙은 없음). 13시부터 통제A 본인 규칙(16시 휴게 권장·17시 휴게 하드·G1 11~15시 중 출근 시간). 통제A가 사실상 마지막 2시간을 쉬는 만큼 일반근무자(준호 포함) n빵으로 나눈다.
- **오후반차**(08~12 근무, 13시 퇴근): 통제A는 08~12시 본인 규칙(08시 휴게·G2·09시 첫 순찰·G1 11~12시). 준호가 마지막 2시간 규칙 계승 — 16시 휴게(강한 권장, 안 되면 G2, 결원 2명 시간이면 G1 금지)·17시 휴게(하드). 이때 준호 17시 휴게는 막타임 직전 수혜 규칙보다 우선(통제A 규칙).
- **연차**: 준호가 통제A 자리(통제A 규칙 전부 계승), 나머지 근무자 기준 결원 1명 더.
- 전일 준호 대행의 근무표에는 A 대신 **1준호**로 표시하고, 나머지 출근자는 2번부터 순서대로 표시한다. PC·폰 본표·분석·CSV·현장 이미지·엑셀에 같은 번호를 쓴다. 내부 역할과 대행 규칙은 유지한다.
- 반차 날 적용 안 하는 통제A 규칙: 포스트 4개 1번씩(반나절 불가), 통제A 피로도 1점 적게(반나절). 통제A 실근무 ≤ 일반근무자는 유지. 준호는 하루 전체 근무라 n빵 비교에 포함.
- 반차일 규칙(10/5)과 같이 평소 하드룰로 해를 못 찾으면 연속 실근무 상한·격차 1을 가능하면 지킬 규칙으로 낮춰 만들고 화면에 경고(예: 결원 1명+오후반차+FM은 피로도 격차 2 경고, 생성 약 1분 20초).

## 8. 확인된 사실 (계산 검증)

- 위 규칙에서 결원 0·1·2명, 미리 정한 반차, 긴급 재편성 모두 생성·독립 검증 통과(2026-10-12~13).
- 결원 2명은 네 포스트를 모두 열면 최대 3연속 실근무 제한 아래 해가 없다(46시간 필요, 5명 최대 40시간) → G2 미운영.
- 결원 1명 FM은 통제A 포스트 1번씩 규칙 때문에 완벽 n빵 불가능(180초 계산 확인) → 1 차이 표.

## 8-0. 미리 정한 반차

- 근무자 상태에 오전반차·오후반차. 오후반차 = 08~12시 근무 후 13시 퇴근, 오전반차 = 13시 출근(13~17시). 나머지 시간은 근무불가(근무 0·휴게 0).
- 반차로 일반근무자가 4명인 시간만 결원 2명 규칙(G2 미운영·최대 3연속). 3명이 되는 시간이 생기면 수기 편성 안내.
- 반차자: 나오는 5시간 중 휴게 1시간(다른 근무자 밸런스 다음), n빵·포스트 최소 1번에서 제외. 반차자 대신 모자라는 순찰은 일반근무자 우선, 없으면 통제A.
- 평소 하드룰을 모두 지키는 표를 먼저 찾고, 없을 때만 연속 실근무 상한·격차 1을 가능하면 지킬 규칙으로 낮춘다(화면 표시).

## 8-1. 긴급 반차·이탈 재편성

- 조작은 야간·평일 주간과 같다: '🚨 긴급 반차·이탈 재편성' → 표의 시간 칸을 눌러 LOCK → 빠지는 사람 → 오후반차/긴급 이탈. 폰은 '몇 시까지 LOCK → 누가 → 종류'.
- LOCK한 시간까지 기존 배정을 바꾸지 않는다. 오후반차는 13시부터, 긴급 이탈은 LOCK 다음 시간부터 근무불가(근무 0·휴게 0).
- 남은 일반근무자가 4명이 되는 시간부터 결원 2명 규칙으로 전환. 3명은 수기 편성 안내.
- 밸런스는 끝까지 근무하는 일반근무자끼리. 빠진 사람은 비교·포스트 최소 1번에서 제외.
- 허용 격차: LOCK 10시까지 1, 그 뒤 2. 연속 실근무 상한·통제A 규칙을 더 어기지 않는 범위에서만 맞추고, 없으면 차이 최소 표 + 화면 안내.
- 긴급 재편성에서만 연속 실근무 상한과 격차는 '가능하면 지킬 규칙'(못 지키면 사람·시간 표시). 나머지 하드룰은 그대로이며 자동 완화하지 않는다.
- [권장] 긴급 오후반차자는 08~13시 중 휴게 1시간만(밸런스 범위 안, LOCK 전 휴게가 더 많았으면 그대로).
- 우선순위: 가능하면 지킬 규칙 위반 최소 → 통제A 추가 순찰 최소 → 일반근무자 차이 최소 → 오후반차자 휴게 1시간 → 같은 포스트 2연속 최소.
- 저장본이 있는 날 재편성표를 저장하면 기존 저장본을 history/weekend_day/.trash에 보관 후 교체.

## 9. 화면·저장

- 근무표와 FM·유도리 전체 비교표(직원·실근무·실휴게·피로도·입식·좌식·순찰 피로도·기타 피로도). 피로도 = 입식×2 + 좌식 + 순찰 피로도 + 기타 피로도.
- 저장본은 날짜를 고르면 바로 표시. 표에 CP 열, 근무자명 두 줄(통제+번호 윗줄, 넘친 번호+CP 아랫줄). PC는 표 오른쪽에 특이사항·비고, 폰은 가로 스크롤 없는 compact 표 + 표 아래 비고.
- 특이사항은 당일 최고·최저 순위가 아니라 반차·결원·통제A·순찰·이력 영향·4연속 등 실제 이유로 설명한다.
- 저장본 실제 근무 수정: 끌어 교환·칸 직접 수정·피로도 ±·사유 기록, 생성 규칙으로 막지 않는다(참고 경고만). 손대지 않은 업로드 저장본은 생성 규칙 검사 대상이 아니다.
- '📊 주말 주간 기록' 표: 저장일별 피로도·실근무·최근 4회 손해 점수·출처. 현장 양식 이미지·엑셀 다운로드.
- 저장 위치 history/weekend_day. 평일·야간 집계와 섞지 않는다.


## 10. 야간과 연계한 순찰 제외 보호·회전 (2026-10-15 사용자 확정)

- HARD: 야간·공휴일 주간의 결원 없는 전일 출근에서 순찰 제외된 일반근무자는 다음 실제 출근 야간·공휴일 주간 2회 각각 순찰 필수. 연차·결근과 평일 주간은 횟수 제외. 같은 날짜는 주간→야간 순서.
- 권장: 필수 규칙·당일 균형·기존 상위 목표 안에서 저장된 혼합 실제 이력 전체의 순찰 제외 횟수가 적은 사람을 제외 우선(0회 우선).
- 이 연계는 순찰 제외·출근만 합친다. 피로도·실근무·차단봉·일반 월간 집계는 기존대로 분리한다.
