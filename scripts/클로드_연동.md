# 코덱스에서 클로드 호출

Claude Code CLI를 이용한 별도 검토 세션이다. 현재 열려 있는 클로드 대화와 연결하지 않는다.

설치 위치: `%USERPROFILE%\.local\bin\claude.exe`

최초 로그인(사용자 브라우저 인증 필요):

```powershell
& "$env:USERPROFILE\.local\bin\claude.exe" auth login
```

로그인 상태 확인:

```powershell
.\scripts\ask_claude.ps1 -Check -Prompt '상태 확인'
```

검토 요청:

```powershell
.\scripts\ask_claude.ps1 -Prompt 'AGENTS.md를 읽고 주말 주간 통제A 긴급 반차 처리에서 확인할 규칙을 정리해줘.'
```

검토 도구는 Read·Glob·Grep만 허용하며 파일 편집·셸 실행·MCP·플러그인·사용자 hook은 켜지 않는다. 결과는 JSON으로 반환한다. 기존 세션 재개 옵션은 사용하지 않는다. 로그인 후에도 실제 모델 응답까지 성공해야 연결 검증 완료다. 계정 사용량은 Claude 계정 기준이다.
